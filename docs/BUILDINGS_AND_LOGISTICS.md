# 《炼器宗》建筑、地图与生产网络

## 文档目的

本文档定义《炼器宗》的地点、设施、本地仓储、四类物流、灾害、游离灵气、聚灵阵和跨地点自动化规则。它回答资源存在哪里、设施如何连接、爆仓会发生什么，以及玩家怎样在手工搬运、资源点工业和聚灵铸币之间选择生产道路。

本文档与其他权威文档的分工如下：

- [GAMEPLAY_FOUNDATIONS.md](GAMEPLAY_FOUNDATIONS.md) 定义开局资源、功能物品、制造方式、工具赋能和首个可玩闭环；
- [MATERIALS_AND_STORAGE.md](MATERIALS_AND_STORAGE.md) 定义物资状态、容器嵌套、批处理、沼井点火和空白灵石；
- [ROADMAP.md](ROADMAP.md) 定义各阶段向玩家承诺什么；
- [MODULES.md](MODULES.md) 定义地点、资源、生产、时间和界面状态分别由哪个模块拥有；
- 本文档定义这些模块共同呈现的建筑与生产网络玩法。

本文档中的明确数值是当前设计基线，不是未经验证便永久冻结的平衡常量。标为“待定”的参数必须通过原型验证后再进入正式数据。

## 核心原则

### 地点拥有真实库存

- 宅院和每个资源点分别拥有本地库存，不存在可以从任意地点直接取用的全局仓库。
- 建筑只读取所在地点或已接入运输线路的资源。
- 主角携带、容器装载、傀儡运输和固定线路运输都是资源跨地点移动的真实方式。
- 固定炼器阵消耗所在地库存；纸质炼器阵消耗主角携带或当前地点可用的资源。

### 地点、设施与物流

- 宅院、资源点、藏经阁和市集属于地点，是M04拥有的世界节点。
- 土堆、固定炼器阵、功法书架、鉴定处和资源输出端属于固定设施；聚灵阵部署后也提供设施功能，但仍是可拆下的额外阵法。设施在启用期间归属于唯一地点，提供储存、生产、捕获、知识或服务等稳定功能，不因共同语义而全部归M06拥有。
- 系统设施由世界或宗门提供，玩家只能按需交互，不能拆除或控制其内部规则。主线要求建成的固定生产与储存设施属于建筑物，建成后不能拆除、搬走或投入炼器阵，但可以控制、停机、维修和按规则升级；矿洞、沼井不允许建设此类建筑物。
- 拓印在空地上的固定炼器阵建成后永久固定，本体可以单独升级；降低泄漏、提高效率等额外能力还可由可更换的外围阵法提供。纸质炼器阵、未建成的器物和家具不是建筑物，可按物品规则携带或投入炼器阵。
- 聚灵阵及布设在固定设施上的额外阵法可以拆下、更换、携带或作为器物继续炼制。聚灵阵没有人为部署数量上限；取消部署前必须按规则处理阵内灵气，取走家具或容器前也必须处理其中物品。
- 导流槽、传送带和天舟的核心职责是跨库存边界运输，因此属于物流而不是设施。

### 设施负责本地功能，物流负责跨边界移动

- 每条运输线路必须具有明确的起点、终点、承载对象、容量、流量、损耗和堵塞状态。
- 导流槽、水槽、传送带等线路只搬运其能够承载的实体或流体，不在途中凭空完成资源转化。
- 熔炼、归元、五行转化、炼器和封灵由对应设施完成。
- 界面中的库存、流向、堵塞和过载必须来自真实模拟状态，而不是只用于表现的动画。

### 自动化改变劳动方式

玩家从亲自采集和携带材料开始，逐步建设本地设施、资源点工厂和跨地点物流。自动化提高持续吞吐并解放主角时间，但不得从不存在的资源源头生成材料。

## 地图与初始宅院

### 初始宅院布局

玩家进入内门后获得一处宅院，初始包括：

| 区域 | 初始作用 |
| --- | --- |
| 卧室 | 安置床、蒲团等休息与恢复类功能物品 |
| 炼器房 | 使用纸质炼器阵、存放炼器相关器物 |
| 柴房 | 储存木头，并承担木材失火风险 |
| 水窖 | 储存水 |
| 土堆 | 储存运回宅院的泥土 |
| 中央空地 | 承载后续拓印和逐步建成的固定炼器阵 |

上述区域不是装饰性房间名称。它们对应真实物品、库存、设施状态和灾害影响范围。

首次游戏中，土堆、柴房和水窖均为空。重置游戏或通关后重新开始时，三处设施分别预置泥土、木头和水各1,000份；该赠送不包含高炉、炎坑、固定炼器阵或其他生产设施。

### 固定炼器阵与纸质炼器阵

当玩家接到“炼器阵拓印”任务后，需要储备足够的基础材料，在中央空地拓印并逐步建立固定炼器阵。

初级固定炼器阵的拓印投入为泥土、木头和水各2,000份。任务界面分别跟踪三种材料的准备进度；制作耗时，以及采用一次提交还是分批投入，留待建设交互原型确认。初级升中级、中级升高级的默认投入与高级升天级的留白，见[《玩法基础规则》](GAMEPLAY_FOUNDATIONS.md)；升级在原址完成，不拆走已建成的阵法本体。

- 固定炼器阵承担宅院的规模化转化、炼器、赋能和自动化控制。
- 固定炼器阵建成后，纸质炼器阵仍然可用，不会被剧情回收或自动替换。
- 纸质炼器阵便于随身携带，可在资源点临时转化灵气、驱动工具或处理当地材料。
- 玩家可按主线建设条件在泥沼、丛林、灵泉、矿脉和熔岩口分别建设固定炼器阵；矿洞和沼井只能使用可携器物及当地交互，不能建设固定设施。

固定阵不是解锁炼器行为的唯一许可证，而是将低吞吐、依赖主角的临时作业升级为稳定生产节点。

### 资源距离层级

宅院周围七处资源地点形成三层获取难度：

| 距离层级 | 资源地点 | 主要玩法压力 |
| --- | --- | --- |
| 近程 | 泥沼、灵泉、丛林 | 徒步采集、基础工具和下品行囊足以完成往返 |
| 中程 | 矿洞、沼井 | 首次远征、点火准备、工具与携带容量开始成为明显瓶颈 |
| 远程 | 矿脉、熔岩口 | 人工往返代价高，推动灵物匣、傀儡、固定阵法和跨区物流 |

矿洞和矿脉分别承担可人工开发的初级金属来源与后期高吞吐金属来源；沼井和熔岩口分别承担中期可点燃气泉与后期工业地火来源。「熔岩口」是地点，「地火」是当地涌出、可在导流槽中流动的物资，「火生灵气」是可供驱动或投入配方的属性灵气。矿洞、沼井是不能建设固定设施的过渡教学地点；其余五处资源点可建设固定设施。宅院加五处可建设资源点，合计可搭设六座固定炼器阵。七个地点仍服务于五行资源体系，不新增额外属性。

熔岩口与矿脉位于远程资源层的不同方向，二者之间的直接导流属于后期大型工程。玩家可以先把金属和火源分别运回宅院，也可以在投入足够建设成本后改为矿区就地熔炼。

当前地点地图的坐标只用于表现。旅行时间、线路长度和建设成本由明确路线数据结算，界面缩放或重新排版不得改变资源获取效率；未来二维六边形大地图若启用地形施工，再由真实地图格和线路规则承担这些计算。

### 主角旅行与交通升级

开局的泥沼、丛林和灵泉与宅院之间立即切换，没有旅行读条。矿洞解锁后开始出现需要等待的旅行，矿脉比矿洞更远；讨论中的矿洞15秒、矿脉60秒仅表示当前距离层级，均非最终平衡数值。旅行开始后目的地锁定，主角占用唯一行动位，读条结束前不能掉头、改道或发起另一项亲力行动；独立运行的阵法与物流照常推进。首次往返可以在旅行期间显示剧情或教程提示，阅读不是抵达条件。

中期的飞索、灵驹等方式提高主角旅行速度，并可顺带载物；当前讨论容量为每种材料20份，不把它们当作大宗物流主力。天舟既能载人，又能大容量载货，可在主角不同行时运输资源点就地加工的高级材料回宅院。后期传送阵可承担更高级的物品转运。载物功能可以留给玩家自行发现，不需要教程直接讲解，但实际容量、装卸状态和费用必须在交互中可见。

v1.0世代的资源点不设置可采尽的资源总量字段；五处可建设资源点的稳定产出仍受设施速度、灵气供给、仓储和线路吞吐限制。矿洞、沼井不建设固定设施，保留手工与可携器物的过渡玩法。未来大地图阶段再考虑在二维六边形地图上按地形布置导流槽和传送带、开发更远的资源点，并允许多个同属性资源点同时产出。唯一基础资源输出设施的约束仅适用于五处可建设资源点；当前阶段不实现资源总量、六边形施工或3D地形。

### 地点显示与进度门槛

首次游戏中，地点按操作教学和生产能力逐步显示：泥沼首先出现，完成首次土生金后显示丛林，首次存放木头后显示灵泉。操作教学结束后，其他地点继续由任务、事件和进度条件揭示。

沼井和矿洞必须等待宅院的初级固定炼器阵拓印完成后才显示。此前玩家尚不具备进入火源与金属工业所需的生产基础，提前显示不形成有效选择。矿脉和熔岩口仍由更后的任务、事件或建设能力解锁。

重置游戏或通关后重新开始时，所有资源地点立即显示并可前往，但地点开放不会赠送所需工具、建筑、图纸或供能。玩家仍需自行拓印固定炼器阵、兴建高炉与炎坑，并满足各项生产工序的真实条件。

### 资源点唯一输出设施

泥沼、丛林、灵泉、矿脉和熔岩口各有且只有一个负责高效取得实体基础资源的固定输出设施。唯一性只约束基础资源采集，不限制玩家在这些地点按主线条件建设固定炼器阵、生产与储存建筑，或部署可拆的聚灵阵等额外阵法。矿洞和沼井不建设固定输出设施，也不计入这一唯一性约束。设施的正式名称可以在对应内容设计时确定；当前只冻结其存在、唯一性与职责：

```text
资源点的真实来源
  → 唯一资源输出设施结算采集、工量与供能
  → 写入设施的本地输出端
  → 玩家或物流从输出端取走
```

玩家在设施建成前仍可依靠主角、基础工具和当地交互进行采集。进入自动化后，提高资源点产量依靠升级设施、改善工具或阵纹、增加供能、维护、扩容和疏通输出端，不允许复制大量同类采集设施来绕过唯一性。资源设施只把产物送到本地输出端，不自动传送回宅院。

资源点还可以拥有受天然流量限制的当地属性灵气。该灵气由聚灵阵捕获，不属于实体资源输出设施的第二个输出端；聚灵阵数量只增加捕获速率和储存容量，不能提高资源点本身的天然灵气产量。

生产型设施（包括五处可建设资源点的输出设施和固定炼器阵）持续运行时需要持续灵气供应；主角也可亲自催动纸质或固定炼器阵，并分段输入自身灵气。对应属性资源点可用当地聚灵阵捕获的天然属性灵气驱动输出设施；傀儡主要承担采集、低级运输和程序化赋能，不是生产设施必需的操作员。炼器阵同轮可在品级允许的金木水火土节点上各运行一条配方，并同时在中央节点运行一条配方；同一属性节点不能运行两条配方。主角的一份驱动灵气可共同催动本轮启用的节点；持续供灵时属性节点消耗对应属性灵气，中央节点可消耗任意属性灵气。各配方投入、驱动、损耗及产出分别结算，具体品级上限见[《玩法基础规则》](GAMEPLAY_FOUNDATIONS.md)。

## 建筑与本地仓储

### 高炉与炎坑

随着游戏推进，玩家可以在合适地点建设：

- **高炉**：消耗火生灵气，将金属熔化为可浇铸或运输的金液；
- **炎坑**：消耗木头，产生火生灵气，并形成必须受控的高温与地火风险。

金属仍然只有“金属”一种。高炉改变金属的处理形态，不引入铜、铁、银或合金材料树。

金液转运、火气加持铁桶、泥土模具和水冷却，以及地火在导流槽中冷却堵塞的规则见[《物资、储物与批处理》](MATERIALS_AND_STORAGE.md)。

### 本地容量

仓储容量按地点和资源种类分别计算。当前基线为：

```text
下品固定炼器阵所对应的本地仓库
  → 每种基础资源容量 10,000
```

“每种基础资源10,000”不是所有资源合计10,000，也不是所有地点共享10,000。更高品级阵法、专用仓储建筑和运输设施如何扩容，尚待后续平衡确定。

行囊、芥子储物器、灵物匣和同名物品堆叠不改变本地库存边界，详细规则见[《物资、储物与批处理》](MATERIALS_AND_STORAGE.md)。

生产设施在写入库存前必须检查可用容量。达到容量上限后，系统不得继续无声产出、静默删除溢出物或将其自动转移到其他地点。

## 四种物流方式

游戏提供四种语义不同的物流方式：

| 方式 | 运行形态 | 主要约束 |
| --- | --- | --- |
| 玩家自行携带 | 离散往返 | 行囊与容器容量、旅行时间、主角占用 |
| 傀儡暂存运输 | 自动离散往返 | 暂存空间、任务指派、供能、工具和往返周期 |
| 机械运输 | 固定连续线路 | 承载对象、流量、方向、堵塞、损耗和维护 |
| 交通工具 | 大批次离散运输 | 货舱、装卸、航线、行程、班次和供能 |

四种方式都必须说明来源、目的地、承载对象、容量、耗时与停机原因，但不能为了共用一种数据结构而抹平差异。玩家和傀儡按装货、移动、卸货结算；导流槽和传送带按连续流量结算；天舟等交通工具按装卸、行程和班次结算。

传送带、导流槽等可由初级升至天级，承担长期、持续、稳定的大吞吐运输。天舟虽可运输基础资源，其主要用途是将各资源点独立阵法合成的高级材料成批运回宅院集中炼器；飞索、灵驹等提速方式的少量储物空间不替代专用物流。傀儡可独自执行运输，当前讨论的暂存容量为1,000；具体容量单位、各品级交通工具的装载与班次仍待平衡。交通工具不必由主角随行，但自主航行的调度条件尚未冻结。

### 资源与灵气的分段分流

资源点的基础资源输出可在已连接的本地加工设施、本地仓储和外运线路之间按玩家设置的比例分流。界面使用随实际去向数量变化的分段滑条：每段对应一个稳定设施或线路标识，相邻分界块拖动时只调整两侧份额，总和保持100%；同时提供数字输入以处理零份额和大量细分去向。新接入的去向初始为0%，不擅自抢走既有份额；拆除去向时不能继续向失效目标分配，其份额如何重置留待交互原型决定。显示目标比例和实际流量，拥堵或停机不能伪装成仍在正常输送。

同地点、同属性的复数聚灵阵在分流界面中视为一个储灵池，保留各阵真实容量与捕获状态。聚灵阵使用同一种分段滑条给当地已连接的生产设施持续供灵，并有固定的“留存于聚灵阵”去向，供玩家之后按属性一次性全量取出。八方阵解锁后，玩家还可把资源点储灵池明确接入跨地图供灵线路，按其品级承担`75%／50%／25%／0%`的远程损耗；接收端必须是部署八方阵的地面固定炼器阵，纸质炼器阵不接收此加成。已分给设施或远程线路并送出的灵气，若接收端吃不下或停机，就在相应地点逸散；不自动转给其他设施，也不退回储灵池。留存份额稳定储存至容量上限，满载后无法捕获的后续灵气按环境逸散规则处理。界面必须显示设定份额、实际消耗、传输损耗和逸散量。

滑条分配与离线结算都由同一套确定性数量和舍入规则执行；比例不能复制资源或灵气。分流的具体刷新粒度、零份额交互和拥堵反馈留待原型验证。

### 跨地点线路

玩家探索资源点后，可以在地点之间建设专用运输通道。例如：

- 从熔岩口向矿脉建设导流槽，将地火引至矿区；
- 从灵泉向丛林建设水槽，将水引至林区；
- 后期使用传送带、运输傀儡或天舟运送基础材料与最终成品。

每条机械线路至少需要结算：

- 来源地点是否有可运输资源；
- 目标地点是否有接收容量；
- 线路当前流量与承载上限；
- 运行所需的供能、维护和容器条件；
- 堵塞、停机、泄漏或破损造成的实际后果。

若目标库存已满，线路应停输、堵塞或依照该线路的物理规则溢出，不得越过本地容量直接写入库存。

## 爆仓与灾害

### 灾害来自可追溯的过载

爆仓不是简单的红字惩罚，而是生产网络中的物理事件。灾害必须能够追溯到具体来源、地点、物质和过载原因。

例如，炎坑或地火线路失去接收能力后：

```text
地火继续涌入
  → 炎坑或导流线路溢出
  → 地火在当地扩散
  → 接触柴房或柴堆
  → 木材被点燃并实际减少
  → 燃烧与泄漏产生游离属性灵气
```

聚灵阵只能收集灾害释放到空间中的属性灵气，不能因此消除地火、积水、燃烧或损坏本身。物理灾害与游离灵气是两个相关但不同的状态。

### 灾害也遵守世界规则

- 灾害不是纯随机事件；相同初始状态、时间推进和玩家输入应得到可复现结果。
- 在线推进与离线结算使用同一套灾害规则。
- 灾害可以造成显著库存损失、停机和修复成本，但必须保留明确恢复路径，不能永久软锁核心流程。
- 玩家可以故意制造泄漏或灾害以回收灵气，只要完整承担原料、设施、时间、容量和事故风险。
- 受控生产在正常情况下应比故意纵火或溢流更稳定、更高效；不需要用世界规则之外的硬禁令阻止怪异玩法。

## 游离属性灵气

### 生命周期

属性灵气离开炼器阵、工具、聚灵阵或其他稳定载体后，进入所在区域的游离灵气状态。

1. 游离灵气获得完整的5秒稳定期；
2. 稳定期内数量不因自然消散而减少，但可以被聚灵阵捕获或被有效工序消耗；
3. 稳定期结束后立即进入连续、快速的衰减过程；
4. 衰减后归零的灵气不可恢复。

玩家从聚灵阵取出灵气后同样获得5秒持有窗口。若窗口耗尽，灵气立即脱离玩家操作并进入衰减，不再获得第二段稳定期。

### 衰减公式

用户体验上，衰减应呈现为前期下降明显、随后逐渐逼近零的曲线。实现使用等价且易于确定性结算的指数形式：

```text
若 t ≤ 5：Q(t) = Q₀
若 t > 5：Q(t) = Q₀ × e^[-λ(t - 5)]
```

其中：

- `Q₀`是进入游离状态时的灵气数量；
- `t`是进入游离状态后的秒数；
- `λ > 0`是待原型验证的衰减常数。

该公式表达了原先“以底数`0 < a < 1`的曲线快速下降”的设计意图，同时避免对数函数在数量接近零时出现定义和方向歧义。最终`λ`、最小结算精度与归零阈值必须集中定义，不能由不同界面各自取整。

### 逸散与再捕获

炼器阵发生转化损耗时，未转化部分先进入当地游离灵气，而不是立即删除。例如：

```text
水生灵气 100
  → 木生灵气 10
  → 水生灵气 90 进入当地游离状态
```

聚灵阵可以在这90点水生灵气消散前将其重新捕获。单纯反复捕获与转化的利用率可以逐步接近100%，但单次纯转化不得超过100%；每一轮仍然需要时间、驱动灵气、设施容量和玩家调度。高产合成再逐级归元形成的净增材料路线另按各次配方独立结算，不套用此处纯转化的上限。

## 聚灵阵

### 定位与首次揭示

聚灵阵是中期自动化过渡的重要组成部分，不是前期跳过采集、容器和基础制造的捷径。

玩家第一次使用纸质炼器阵并看到大量灵气泄漏时，剧情立即揭示问题。主角产生类似以下思考：

> 天啊！灵气都漏光了，这怎么办？我要不去问问藏经阁的长老吧。

随后自动领取任务：

```text
向内门藏经阁长老询问聚灵阵相关信息
```

向长老询问后，玩家理解聚灵阵的用途并完成这项认知任务。购买图纸是独立的长期目标，不应让“尚未买得起图纸”阻塞主线教程继续推进。

这次对话同时解锁商店系统。商店不会因此开放五行基础材料交易，也不会免费赠送聚灵阵。玩家可以选择购买可重复制造初级聚灵阵的图纸，或者在商店以更高总价直接购买聚灵阵成品；成品的最终报价仍待经济原型验证。

初级聚灵阵图纸的当前讨论价格为：

```text
下品金灵石 ×1
下品木灵石 ×1
下品水灵石 ×1
下品火灵石 ×1
下品土灵石 ×1
```

这形成真实的资本门槛：规则很早公开，能力要到玩家建立足够生产基础后才能取得。若玩家坚持在前期手工生产五块灵石，系统允许这样做，但必须完整结算其高昂成本。

按当前下品属性灵石和`1000份基础资源 → 100点属性灵气`的基线，五块不同属性的下品灵石合计需要每种灵气600点，也就是每种基础资源6000份、五种共30,000份。若每100点转化需要一轮，单是30轮驱动还需1500点主角灵气，且尚未计入凝结、灌注和封灵工序。

为避免循环依赖，聚灵阵解锁前必须至少存在一条能够取得五种下品属性灵石的真实路径，例如手工生产、交易或明确任务奖励；不得要求玩家先拥有聚灵阵才能购买聚灵阵图纸。

### 部署、属性与容量

- 聚灵阵不设置人为的部署数量上限；实际规模由材料、建造时间和管理成本约束。
- 每座聚灵阵部署时指定一种需要捕获的属性灵气。
- 聚灵阵初级、中级、高级、天级容量分别为100、1,000、10,000、100,000点属性灵气。
- 初级聚灵阵在宅院中的捕获速率为每秒1点。
- 初级聚灵阵在对应资源点附近的捕获速率为每秒5点。
- 聚灵阵只在当前区域存在目标属性的游离灵气且自身仍有容量时工作。
- 灵气进入聚灵阵后稳定储存，直到经玩家设置的分流送给设施、被玩家全量取出或阵法取消部署；留存部分不自然消散。
- 资源点的天然属性灵气流量、聚灵阵总捕获速率和总储存容量是三个不同的量；增加聚灵阵不能复制或放大天然源头。

取消部署时，阵内储存的灵气释放为当地游离灵气，按游离灵气的一般生命周期结算；不会被无损装回玩家库存。取消部署的操作时长和是否允许在阵法工作时立即执行仍待原型验证。

### 区域聚合管理

同一区域的所有聚灵阵通过一个界面管理，并按目标属性聚合显示。聚合状态至少包括：

- 该属性的聚灵阵数量；
- 总容量；
- 当前储量；
- 当前总捕获速率；
- 当地天然灵气流量或当前可捕获游离量；
- 是否存在可捕获的游离灵气；
- 满仓、停机或阵法失效原因。

例如，同一区域部署20座初级聚灵阵，每4座负责一种属性，则每种属性显示为：

```text
储量：0 / 400
宅院总捕获速率：4 / 秒
资源点总捕获速率：20 / 秒
```

因此，资源点附近18座捕获水生灵气的初级聚灵阵，可以在1秒内接收90点尚未衰减的水生灵气，前提是它们拥有足够空余容量。

### 全量取出与单向操作

- 玩家只能一次取出某一属性分组中当时仍储存的全部灵气，不能指定部分数量；已送进设施的灵气不可取回。
- 界面必须明确写出“取出全部 N 点”，不能把全量取出伪装成普通点击。
- 取出的整团灵气可以在5秒内依次投入多个有效接收端；每次投入扣除实际用量，剩余部分沿用原始截止时间，不重新计时。
- 玩家不能把手中的灵气主动塞回聚灵阵。
- 超时后，剩余灵气脱离玩家操作并进入当地游离状态；同一区域仍有空余容量的聚灵阵会同时开始重新捕获。
- 超时后的再捕获是经过环境的有损回收，不是“撤销取出”或手动回存；灵气在被阵法实际捕获前不会获得第二段稳定期。若它已经重新进入阵内稳定储存，玩家之后再次执行全量取出，则开始一次新的5秒持有窗口。

“拿在鼠标上”是桌面界面的表现方式，不是领域规则。键盘和触控操作必须提供等价的选取、计时、投入和取消反馈。

### 捕获与衰减的结算

稳定期结束后，聚灵阵捕获与自然衰减同时发生；资源点若存在持续天然流量，则同时加入明确的环境来源。概念模型为：

```text
dA/dt = G - λA - R
dS/dt = R - D
```

其中：

- `A`为当地尚未捕获的游离灵气；
- `S`为聚灵阵已储存灵气；
- `G`为当前资源点明确提供的天然属性灵气流量；普通泄漏事件中`G = 0`；
- `R`为不超过阵法总速率、剩余容量和当前游离量的实际捕获速率。
- `D`为按玩家分流设置从聚灵阵储量送出的灵气；设施实际消耗与吃不下而逸散的部分都包含在内，手动全量取出另按离散事件结算。

实现可以采用等价的分段或批量结算，不要求逐帧模拟，但必须保证：

- 相同输入得到确定结果；
- 在线推进与离线结算等价；
- 捕获量与消散量之和不超过原有游离灵气；
- 聚灵阵送出的灵气与留存的灵气之和不超过实际捕获和已有储量；
- 多座阵法聚合后不会因帧率、遍历顺序或小数舍入凭空增加灵气。

## 资源点的三种开发路线

同一资源点允许玩家采用或混合三种开发方式：

```text
手工采集
资源点 → 主角与工具 → 玩家携带基础资源

工业开发
资源点 → 唯一资源输出设施 → 本地加工与自动物流

灵气铸币
资源点天然属性灵气 → 海量聚灵阵 → 天品纸质炼器阵
→ 现场批量灌注与封灵 → 玩家携带属性灵石离开
```

第三条路线不要求玩家在当地布置傀儡或固定炼器阵。玩家可以携带空白灵石和天品纸质炼器阵定期巡回资源点，一次性取出当地同属性聚灵阵中的全部灵气，并在5秒窗口内现场制造属性灵石。它保留了玩家携带这一早期物流方式在后期的战略价值。

巡回铸币必须完整承担聚灵阵布设、天然流量上限、等待时间、空白灵石运输、纸质炼器阵品级与批量、全量取出操作、成品储存和回程运输。纸质炼器阵不能获得外围阵法加成，其高品级灌注损耗须如实结算。固定炼器阵擅长持续、可接入自动物流的无人生产；纸质炼器阵擅长主角亲自参与的机动批处理，两者不得互相淘汰。

## 中后期生产网络

### 中期：从回收损耗到局部自动化

中期聚灵阵主要承担：

- 捕获纸质或固定炼器阵的逸散灵气；
- 回收灾害和资源点环境中的游离灵气；
- 为当地炼器、工具赋能和自动化设施提供临时缓冲；
- 迫使玩家为“全量取出”的灵气提前准备足够接收端。

聚灵阵不是通用仓库。其单向取出、全量操作和有限容量，使玩家必须把收集、使用和生产批次组织成真实流程。

### 后期：资源点工厂

天级炼器阵与天级聚灵阵组合后，可以在资源点：

- 从明确存在的天然资源、环境流量和运输输入中批量取得基础材料；
- 就地完成转化、熔炼和炼器；
- 将最终成品通过传送带、运输傀儡或天舟送回宅院。

这不是从灵气中免费创造物质。所有批量产出仍必须绑定真实的当地资源源头、可解释的五行做功、设施吞吐和仓储容量。

高阶阵法联动可以用自动调度替代玩家的鼠标操作，但仍需存在明确的分流、取出、路由和接收状态；设施只接收玩家已连接并分配的持续供灵，不能任意读取整个聚灵阵库存。

长期生产形态为：

```text
前期：主角 + 基础工具 + 纸质炼器阵
  → 中期：固定设施 + 聚灵阵 + 本地自动化
  → 后期A：资源点工厂 + 跨地点物流 + 宅院集中调度
  → 后期B：海量聚灵阵 + 天品纸阵 + 主角巡回铸币
```

## 体验与验收不变量

- 第一次纸质炼器阵泄漏必须触发可理解的反馈和询问聚灵阵的任务，不把损耗藏在数值变化里。
- 与藏经阁长老完成聚灵阵认知对话后才解锁商店；购买聚灵阵图纸或成品不是完成该认知任务的条件。
- 首次游戏按教学阶段显示资源地点；重置或通关后重新开始立即显示全部地点，但不跳过设施建设与生产条件。
- 聚灵阵概念可以前期出现，但玩家在取得昂贵图纸前仍能继续核心流程。
- 地点库存、主角携带与线路运输不得退化为同一份全局资源数字。
- 下品固定炼器阵对应仓库的每种基础资源容量按10,000的当前基线真实结算。
- 满仓会停机、堵塞或依照物理规则引发灾害，不会静默吞掉产物。
- 灾害产生的游离灵气与地火、燃烧等物理状态分别存在；收集灵气不会自动修复灾害。
- 初级聚灵阵容量、地点速率、目标属性和无部署上限规则必须由真实状态驱动。
- 资源点天然灵气流量与聚灵阵捕获速率分别结算；增加聚灵阵不得增加天然产量。
- 玩家只能全量取出同区域同属性的储存灵气，不能部分取出或手动放回。
- 同一次取出操作的5秒期限不会因分批使用或超时掉落而刷新；超时灵气必须先被阵法实际捕获，才能在下一次取出时获得新的持有窗口。
- 所有泄漏、消散、捕获、灾害、运输和离线推进都必须可复现，并与动画帧率无关。
- 单次纯转化效率不超过100%；高产合成与归元的跨操作净增材料属于已允许的配方循环，不用纯转化效率上限否决。
- 任一错误建设、爆仓或关键设施损坏都必须保留成本明确的恢复路径。

## 待验证与待定事项

- 游离灵气指数衰减的首轮原型半衰期为30秒（`λ=ln(2)/30秒`）；结算精度、归零阈值及正式平衡仍待验证；
- 初级聚灵阵的建造工量、占地和维护成本；
- 初级聚灵阵图纸的最终价格，以及是否维持五种下品属性灵石各一块的讨论基线；
- 商店直接出售的初级聚灵阵成品价格、库存和补货规则；
- 取消部署的操作时间、受灾或工作状态限制；
- 更高品级炼器阵和专用仓库的容量与速率成长曲线，以及聚灵阵更高品级的捕获速率；
- 各类线路的容量、损耗、维护、破损与修复规则；
- 七处资源地点的最终旅行时间、路线关系与地形修正；
- 沼井的天然流量、熄灭条件和事故规则；
- 炎坑、高炉、柴房、水窖和土堆的最终占地、配方与灾害耐受；
- 灾害扩散、扑救、修复和离线结算的具体数值；
- 传送带、运输傀儡与天舟各自适用的距离、货物和供能边界；
- 七处资源点各自的天然属性灵气类型、流量、周期与可积蓄上限；
- 天品纸质炼器阵在巡回铸币中的批量与操作时间。

上述项目应在对应玩法原型中逐项验证，不得由界面或实现代码自行补全。
