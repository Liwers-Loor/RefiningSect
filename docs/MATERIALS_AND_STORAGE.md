# 《炼器宗》物资、储物与批处理

## 文档目的

本文档定义《炼器宗》的物资语言、储物器物、嵌套库存、物品堆叠、批量容器，以及金属与地火加工状态在储运中的共同规则。它回答物资能够放在哪里、容器怎样互相容纳，以及一整箱物资怎样被运输、交易、炼制或摧毁。加工状态与工序由M05拥有，本文只记录这些状态经过容器和物流边界时必须遵守的行为。

本文档与其他权威文档的分工如下：

- [GAMEPLAY_FOUNDATIONS.md](GAMEPLAY_FOUNDATIONS.md) 定义开局物品、制造方式、工具赋能、灵石基础和首个可玩闭环；
- [BUILDINGS_AND_LOGISTICS.md](BUILDINGS_AND_LOGISTICS.md) 定义地点、本地仓储、运输线路、灾害、聚灵阵和跨地点生产网络；
- [MODULES.md](MODULES.md) 定义资源、容器、炼器、物流、灵石、交易和存档状态分别由哪个模块拥有；
- 本文档定义物资及其容器在上述玩法中共同遵守的行为规则。

明确数值是当前设计基线。尚未确认的容量、速率、配方和损耗必须通过原型验证，不得由实现自行补全。

## 世界语言与物资分类

### 使用世界内成立的描述

游戏使用玩家能够从修仙世界中直接理解的词语描述物资与变化：火、金液、岩浆、冷却、凝固、归元、灌注、封灵、采掘和置换。

- 不用现代凝聚态物理解释火、灵气或材料状态；
- 不在游戏世界中引入“萃取”概念；
- 物资按五行属性及其对应方式归元，不通过现代化学分类扩张材料树；
- 现代工程类比只用于幕后校验机制，不进入角色台词、物品说明或教程文案。

### 五种基础资源与灵石器物

M02只定义以下五种基础资源：

```text
基础资源
├─ 金属
├─ 木头
├─ 水
├─ 火
└─ 泥土
```

五种基础资源具有对应的归元关系。这里的“基础”表示玩家可操作规则中的原语，不表示世界在形而上意义上只能由五种纯物质构成。基础资源「火」以可流动、会冷却的**地火**为实物形态；配方投入的「火 ×N」即投入「地火 ×N」，不另设可独立入库的虚态火。地火与「火生灵气」分开记账，也不拆成泥土与火气两份可操作库存。地火冷却后归入泥土，其热状态与冷却工序由M05处理。

空白灵石和属性灵石是M07拥有的器物，不是M02的第六种基础资源。二者仍可储存、运输、交易并参与配方或供能，但都不能归元；五元素材料20%的通用归元率不适用于灵石。

器物也可以作为后续配方的材料；能否归元仍由各器物的实际工序决定。纸质炼器阵、聚灵阵、外围阵法和家具等可携器物可以按库存规则转移或投入炼器阵。固定建筑建成后不再是可搬运的器物，不能从宅院或资源点拆下作为配方投入；其可拆的附加阵法仍保持独立器物身份。拆取储物家具或聚灵阵前，必须按各自规则处理其中物品或灵气。

材料没有品级，可按构成中不同五行属性的数量标记为二元素、三元素、四元素材料；该标记不把复合材料提升为M02的新基础资源。当前明确的五元素配方产物只有作为器物的空白灵石，尚未定义其他五元素材料。二元素材料须由不同属性的基础材料和属性灵气，或两种不同属性的基础材料合成；同属性的两份投入不能靠件数凑成“二元素”。具体路线与配方解锁见[《玩法基础规则》](GAMEPLAY_FOUNDATIONS.md)。

界面不显示“灵石无法归元”，也不为它们提供置灰的归元按钮。归元界面只列出实际存在归元规则的物资。

## 库存、容器与稳定身份

### 地点和容器都是库存边界

- 宅院、资源点、地面、商店交付位和设施输入输出位可以作为库存根节点；
- 行囊、玉牌、戒指、木桶、铁桶、灵物匣和仓库设施提供具体容器能力；
- 每件物品或材料堆在同一时刻只能属于一个地点或容器；
- 生产设施只读取明确接入或选中的容器，不递归搜索玩家拥有的全部物资；
- 界面、存档和运输系统不得另外维护一份彼此可能不一致的库存副本。

游戏保存的是带稳定标识的扁平归属关系，而不是把一整棵容器内容反复嵌入父物品。玩家看见的是层层嵌套的芥子空间，领域状态保持为可校验的容器树。

### 下品行囊基线

玩家开局持有一件下品行囊。当前基线为：

- 每种材料最多携带100件；
- 不按材料的品级限制存取，因为材料没有品级；复合材料和高品空白灵石仍可装入；
- 同种材料共同占用该材料的件数上限；
- 工具、家具和储物器物另按各自的储物单位占用空间，具体数值待定；
- 宅院物资仍必须存放在柴房、水窖、土堆、阵法仓库等指定设施中，不自动汇入行囊。

更高品级的行囊、储物玉牌、储物戒指和仓库设施提供更高容量或更强容器能力，但不会生成跨容器统一管理界面。

主角没有行囊时仍可随身携带物品，但每一种物品最多只能携带1件；物品种类数没有额外上限。这个规则允许同时携带大量不同种类的单件物品，不把“无行囊”解释为完全不能携带。行囊提高同类物资可携带数量，其具体品级容量继续按对应器物规则结算。

## 芥子空间嵌套

### 品级约束

芥子储物器可以装入另一件芥子储物器，但外层品级必须严格高于内层品级。例如：

```text
天品行囊
└─ 上品储物玉牌
   └─ 中品储物戒指
      └─ 下品行囊
```

- 同品级储物器不能互相嵌套；
- 低品级储物器不能容纳更高品级储物器；
- 容器不能放入自身或自己的任一后代；
- 普通材料和器物不受这条品级限制，只受外层容器的接受规则与容量限制。

该规则用世界内的品级关系限制嵌套深度，避免同品行囊按指数无限扩张容量。

### 外层容量如何计算

内层容器的物资不重复占用外层容量，外层只计算内层储物器本体的储物单位。移动外层容器时，其全部后代随之移动，内部归属不变。

玩家必须逐层打开容器：

```text
天品行囊 > 上品储物玉牌 > 中品储物戒指 > 下品行囊
```

系统不提供跨容器的全局搜索、递归汇总、自动整理或“从任意容器自动凑齐配方”。面包屑、当前层容量和直接内容必须清晰显示，困难来自玩家自己的仓储安排，而不是界面隐瞒当前层状态。

## 同名物品堆叠

### 玩家界面统一堆叠

同一直接容器中的同名物品统一折叠显示，无论它们是否为空、装有物资或已经满载。例如：

```text
下品行囊 ×8
├─ 空置 ×2
├─ 使用中 ×4
└─ 已满 ×2
```

点击该物品堆后，才展示每件行囊的独立状态、容量和可继续进入的内容层级。分组不得跨越当前容器或地点，不能把宅院、资源点和不同芥子空间中的同名物品合并成一堆。

### 数量堆与实例组

玩家只需理解“同名物品会堆叠”，领域内部需要区分：

- **材料数量堆**：同种且无独立状态的材料可以由一条数量记录表示；
- **器物实例组**：行囊、工具、家具和其他拥有内容、耐久、加持或任务状态的器物仍保留独立标识，只在界面按名称分组。

物品堆不是第二份权威状态。批量移动、出售或归元仍然作用于玩家实际选中的具体实例，并按每件器物分别计算容量和后代内容。

## 整体转移、归元与摧毁

装有物资的储物器物可以出售、归元或被灾害摧毁。处理外层容器时，必须先生成完整的子树结算计划，再一次性提交：

```text
选择目标容器
  → 找出容器及全部后代
  → 校验交易、配方、容量和锁定状态
  → 展示将被转移、消耗或损毁的内容
  → 原子提交结果
```

- 出售容器时，容器及被接受的内部物资一并转移，价格不得重复计算外层汇总和内层明细；
- 委托提交必须检查全部后代，不能把不符合条件的物品藏在内层容器中绕过规则；
- 连匣归元会消耗容器本体及其全部后代；
- 灾害可以摧毁容器并连带损坏内部物资，具体掉落、抛出和损失规则由灾害类型决定；
- 非空容器不得因保存、迁移或界面整理被静默清空；
- 正在运输、交易或炼制的容器必须被锁定，不能同时被再次移动或提交。

危险操作应显示实际影响，但不以强制禁令替玩家避免所有错误选择。

## 灵物匣与批处理

### 定向容器

中后期玩家可以制作灵物匣，为其指定一种需要接收的材料。只有空匣可以改变指定材料。

```text
灵物匣
├─ 指定材料：木头
├─ 当前储量：736
├─ 容量：1,000
└─ 状态：收集中
```

同名灵物匣仍在当前层级折叠显示，展开后区分空置、收集中、已满和已封匣状态。玩家负责配置各只灵物匣及其线路，系统不自动决定哪种材料应该放进哪只匣子。

### 整匣运输与生产

灵物匣将逐件物流升级为批次物流：

```text
指定材料
  → 接收线路输入
  → 达到目标批量
  → 封匣
  → 整匣运输、提交、出售或投入炼器阵
```

中级和高级炼器阵可以设置最低启动批量、最佳批量、输入容器和输出容器，不必每收到一件材料就启动一次。

投入容器时必须区分：

- **整匣投料**：处理匣内材料，容器本体从输出端返回；
- **连匣归元**：容器本体及全部后代一并归元。

空匣回流是物流网络的一部分。输出端满仓、回流线路中断或输入匣不足都应产生真实停机，而不是由系统自动生成新容器。

## 热状态与材料变化

### 共用热状态

金液、地火、容器加持和水冷却使用M05拥有的同一套确定性加工状态，不分别编写互不相干的倒计时。M06只负责容器、位置和运输，M01负责确定性推进。概念关系为：

```text
当前热量
  = 初始热量
  - 随时间产生的散热
  + 火生灵气提供的维持
  - 水带走的热量
```

界面显示可理解的状态、剩余时间和火气余量，不显示现代物理学解释。加工状态必须在线、离线等价推进；将容器放入行囊、戒指或灵物匣不会暂停冷却。M05提交加工前后的基础资源变化，M02按单次操作校验数量、投入、产出与泄漏，不拥有“金液”这种额外资源类型。

### 金液、铁桶与泥土模具

```text
固态金属
  → 高炉投入火生灵气
  → 金液
  → 装入铁桶
  → 倒入泥土模具
  → 冷却
  → 固态铸件
```

- 金液装入铁桶后持续冷却；
- 火生灵气加持铁桶可以大幅延长金液保持流动的时间；
- 未在凝固前倒入模具，金属会在桶内凝固并形成“凝金铁桶”；
- 凝金铁桶失去容器功能，但仍可出售、整体归元或通过后续工序回收，不会无声删除金属；
- 金液进入泥土模具后显示冷却时间；
- 玩家只有携带装有水的水桶，才能向模具浇水并消耗实际水量来缩短冷却；
- 水离开水桶后回到当地环境过程，具体流散表现待定，不新增可库存的现代材料分类。

泥土模具是否一次性破坏、能够回收多少泥土，以及水冷却的具体倍率尚待原型验证。

### 地火、导流槽与堵塞

地火在物资表现上是持续流动的岩浆；其远程来源地点名为「熔岩口」。岩浆离开地火环境后会冷却，冷却后归入泥土，不另设岩石材料。

- 导流槽需要火生灵气加持，才能长期保持岩浆流动；
- 导流槽本体可由金属与泥土合成，制造时不必消耗属性灵气；火气加持是线路运行条件，不追加入制造配方；
- 线路越长，维持流动所需的火气越多；
- 火气供给不足时，岩浆逐渐减速、凝固并堵塞线路；
- 堵塞物可以用铲子或对应设施清理并取得泥土；
- 地火到达生产节点后，可以将产出的一部分火气回供导流槽，形成需要先行启动的自维持线路；
- 末端停机、满仓或回供中断时，线路仍可能冷却和堵塞。

具体散热、回供比例、堵塞进度和清理工量待原型验证。

## 沼井与点火链

### 天然可燃气泉

沼井是天然甲烷气泉。在游戏中只描述为“一种可以点着的气体”，不把甲烷作为可取得、储存、运输、交易或炼器的材料。

沼井保存的是地点状态和天然流量，而不是“甲烷×N”的库存。玩家不能用木桶、行囊或灵物匣装走甲烷。

### 开局可行的点火方法

第一次启动沼井需要区分被归元的木头和实际燃烧的木头：

```text
木头 A
  → 通过炼器阵得到火生灵气

火生灵气
  + 木头 B
  → 点燃木头 B

燃烧的木头 B
  + 沼井气体
  → 点燃沼井
```

“木头＋炼器阵”是玩家初次抵达时最容易取得的点火路径，不是唯一被硬编码允许的答案。后期已经燃烧的器物、地火或其他足够的有效火源也可以完成点火。

### 点燃后的火气流

点燃沼井后，天然气泉提供受流量限制的当地火气来源。产生的火气必须在当地炼器、设施驱动、游离泄漏和聚灵阵捕获之间真实分配，同一份流量不能被多个用途重复使用。

玩家可以把纸质炼器阵和可拆的聚灵阵带到沼井旁，临时使用或捕获产生的火气；沼井是过渡教学地点，不能建设固定炼器阵、固定采集设施或固定仓储，不发展为固定自动化节点。点燃状态、熄灭条件、天然流量和事故规则尚待原型验证。

## 灵石器物与灵脉采掘

### 灌注与永久稳定

空白灵石由五行属性灵气凝结而成，但形成后没有归元方式；完成灌注与封灵的属性灵石同样不能归元：

```text
五行灵气
  → 凝结为空白灵石
  → 灌注并封灵为属性灵石
```

属性灵石完成封灵后永久稳定，不随时间逸散、降品或产生维护成本。同属性、同品级的灵石没有独立剩余能量，可以按数量堆叠。属性灵石作为供能物时，一旦提交给阵法、傀儡或其他接收端便不可撤回；系统不产生玩家可以取出的“部分放能灵石”，也不记录每块灵石的剩余电量。工序中断时已提交灵石如何结算仍需在对应供能原型中确定，但不得重新变成可自由取用的半耗灵石。

炼器阵的灌注损耗与其品级绑定：初级、中级、高级、天级炼器阵的基础灌注损耗分别为`0%`、`20%`、`40%`和`60%`。品级越高，炼器转化越高效，直接灌注反而越浪费；高品阵法依靠更大的批量、品级兼容和外围阵法弥补这一代价。具体灌注与外围阵法规则见[《玩法基础规则》](GAMEPLAY_FOUNDATIONS.md)。

### 交易例外

商店开启后，金属、木头、水、火和泥土这五种玩家能够直接取得的基础材料不能买卖。加工器物、图纸、工具、灵石和其他生产服务仍可交易。

五种基础资源都不能交易；空白灵石作为M07器物可以交易。当前价格基线为：

```text
任意下品属性灵石 ×1
  → 下品空白灵石 ×1,000
```

这是标准批量报价，不代表商店替玩家自动解决携带与品级选择。

### 品级压缩与阵法兼容

空白灵石当前采用每8块向上一品的等值压缩：

```text
下品空白灵石 ×8 → 中品空白灵石 ×1
中品空白灵石 ×8 → 上品空白灵石 ×1
上品空白灵石 ×8 → 天品空白灵石 ×1
```

这与属性灵石受市场垄断影响的向上`12:1`、向下`1:8`兑换，以及配方、建设和一般供能中的相邻品级`16:1`低品替代都不是同一套规则。固定炼器阵装设归一阵后，其功能供能的低品灵石替代数量另按归一阵品级计算。空白灵石能否在商店外向下拆换，以及玩家自行压缩所需的阵法品级，仍待确定。

下品行囊只能携带同种材料100件，因此1,000块下品空白灵石装不下，压成125块中品仍然装不下。继续将其中32块中品压成4块上品后，可以用93块中品和4块上品表示相同价值，共97件，能够装入行囊。

压缩后的空白灵石不一定能够立刻使用：

```text
初级炼器阵：最多灌注下品空白灵石
中级炼器阵：最多灌注中品空白灵石
高级炼器阵：最多灌注上品空白灵石
天级炼器阵：可以灌注天品空白灵石
```

高品空白灵石可以被低品行囊携带，但不能被低品炼器阵灌注。交易界面应分别显示“是否装得下”和“当前阵法是否能够灌注”，由玩家选择收货品级，不自动替玩家做最优仓储决策。

### 灵脉采掘阵

后期玩家可以向宗门购买昂贵的灵脉采掘阵，在灵石矿脉中消耗空白灵石，置换出已经灌注完成的属性灵石。

```text
空白灵石
  + 灵脉采掘阵
  + 灵石矿脉的天然储量或流量
  + 驱动时间与供能
  → 属性灵石
```

空白灵石是采掘耗材，不是被原地灌注后返还。属性灵气来自灵石矿脉这一明确天然来源。采掘阵必须受到矿脉属性、天然流量、阵法吞吐、空白灵石品级和当地物流限制，不能脱离矿脉运行。

人工灌注提供地点自由和属性控制；灵脉采掘提供高吞吐量，但需要昂贵设施、固定地点、持续耗材和跨地点物流。

## 状态所有权与结算不变量

- M02只拥有五种基础资源、五种属性灵气、数量精度、五行关系、逐次结算与逸散；
- M04拥有地点、距离、可达条件和天然资源点；
- M05拥有归元、熔炼、金液与地火冷却、成器、模具加工及其他配方和加工状态；
- M06拥有容器树、仓储容量、灵物匣、批次输入输出和跨地点运输；
- M07拥有空白灵石、灌注、永久稳定、品级替代、不可撤回供能提交和灵脉采掘规则；
- M08负责可交易范围、报价、支付和空白灵石品级兑换服务；
- M14保存、校验和迁移稳定标识及容器归属，但不成为库存的第二权威来源。

所有容器移动、子树消费、加工状态推进、批次生产和灵石变化必须满足：

- 在线与离线使用同一套确定性规则；
- 物资不能因界面堆叠、嵌套移动或交易失败而复制或丢失；
- 时间状态不会因物品进入芥子空间而暂停；
- 每次操作的投入、产出、泄漏、损毁与配方之外的环境来源可追溯；合法的高产合成和逐级归元循环不受跨操作总守恒检查拦截；
- 错误选择可以造成成本，但核心流程保留明确恢复路径；
- 界面只展示世界中实际存在的动作，不用禁用项讲解不存在的机制。

## 待验证与待定事项

- 各品级储物器物的材料容量、器物储物单位和制作成本；
- 储物器物出售、归元和受灾时的确认层级与内部物资损失规则；
- 灵物匣的容量、封匣工量、回流方式和各级炼器阵的批次阈值；
- 金液、地火、铁桶和导流槽的加工状态参数；
- 火气加持铁桶的容量与持续时间，以及导流槽的单位长度维持成本；
- 泥土模具是否一次性、泥土回收比例和水冷却倍率；
- 沼井点燃后的持续状态、熄灭条件、火气流量和事故规则；
- 空白灵石在商店外的向上压缩、向下拆换和对应阵法要求；
- 灵脉采掘阵的配方、品级兼容、置换比例、天然流量和产出属性规则；
- 灵石提交供能后遇到工序中断、设施损坏或输入锁失效时的最终结算。

上述项目应在对应玩法原型中逐项确认，不得用界面特例或隐藏补贴代替正式规则。
