# 《炼器宗》玩法基础规则

## 文档目的

本文档记录《炼器宗》首个可玩闭环及后续生产成长共用的玩法规则，回答玩家可以做什么、资源如何转化、功能物品如何生效，以及错误选择如何恢复。

本文档与现有权威文档的分工如下：

- [ROADMAP.md](ROADMAP.md) 定义各阶段向玩家承诺什么；
- [MODULES.md](MODULES.md) 定义规则、状态与跨模块协作由谁负责；
- [VERSIONING.md](VERSIONING.md) 定义页面版本号的生成与递进方式；
- [MATERIALS_AND_STORAGE.md](MATERIALS_AND_STORAGE.md) 定义物资语言、材料状态、嵌套储物、批处理与空白灵石；
- [BUILDINGS_AND_LOGISTICS.md](BUILDINGS_AND_LOGISTICS.md) 定义地点、建筑、本地仓储、灾害、聚灵阵与跨地点生产网络；
- 本文档定义跨模块玩法如何在玩家面前成立。

本文档不是完整配方表、最终数值表或内容制作清单。尚需原型验证的数值使用“当前基线”或“待定”标记，不得在实施时将示例自动解释为最终平衡结论。

## 设计原则

### 启发式教程

- 首次游戏使用一次明确的操作教学，通过箭头、聚焦和暂停帮助玩家完成摆放阵图、装土、转化与首次赋能；操作教学结束后，不再持续规定唯一正确顺序。
- 机制教学保持启发式：玩家应通过物品功能、资源变化、行动结果和世界反应理解规则，后续新信息可以只以`!`提示有新消息。
- 不告诉玩家“应当怎样做”，不等于隐瞒物品的当前功能、操作代价或不可逆后果。
- 玩家应能选择低效、奇怪甚至自我惩罚的路径，只要该路径遵守世界规则并保留恢复手段。
- 重置游戏或通关后重新开始时，操作教学默认关闭，但任务、剧情事件和实际规则仍然正常运行。

### 劳动方式成长

成长不只是同一动作的数值变大，也要改变谁在劳动、使用什么驱动、是否必须由主角在场，以及资源如何运输。

```text
徒手与基础工具
  → 属性灵气赋能工具
  → 灵气动力工具
  → 作业傀儡
  → 固定采集与加工设施
  → 端到端自动化网络
```

自动化不是执行某项生产的许可证。玩家原则上可以用人力完成底层流程，自动化的价值是将不可持续的人工劳动变成稳定工业。

### 主角行动与即时采集

主角在任何阶段都只有一个亲力行动位，不随境界或版本增加。打坐、睡觉、亲自催动炼器阵、转化与灌注等灵气相关行动由主角完成；交易、前往藏经阁取得功法等非专属事务可以交给傀儡。打开纸质炼器阵的操作面板时，主角只能执行该面板允许的阵法操作，不能同时挖土、取水或砍树；批量队列具备持续供灵后，阵法可以独立运行，主角才可离开面板做别的事。查看任务、剧情和库存等信息本身不占用行动位。

手工采集是一次点击、一次立即结算的原子动作，没有持续进度和取消操作。容器满时不能继续装入；容器品级只提高容量，不因容量变大而提高单次采集量。铲子、其他辅助工具或相应灵气赋能可以提高单次采集效率。采集量、容器剩余空间与资源变化仍由模拟规则结算，不由动画帧率决定。

### 真实结算与可恢复性

- 物品、工具、家具和设施的功能必须来自真实状态，不是界面中不受模拟约束的开关。
- 玩家主动归元、出售或耗尽功能物品时，其提供的能力会真实消失。
- 失败和错误决策可以造成明显的时间、效率与机会成本，但不得使核心流程进入不可恢复的软锁。
- 所有持续行动、工作进度、灵气逸散和离线推进都使用同一套确定性规则。

## 开局状态与功能物品

### 首次游戏与重新开始

首次游戏承担完整的新手引导。宅院中的土堆、柴房和水窖均为空，玩家没有任何基础资源，需要按剧情前往泥沼、丛林和灵泉建立第一批库存。

玩家从进入游戏起即可使用“重置游戏”。该入口既允许玩家主动跳过初期教学，也用于开发阶段反复测试剧情流程，不要求先完成某个教学节点。

重置游戏或通关后重新开始时使用以下基线：

- 土堆预置泥土1,000份；
- 柴房预置木头1,000份；
- 水窖预置水1,000份；
- 所有资源地点立即显示并可以前往；
- 操作教学提示默认关闭；
- 后续任务、事件和剧情仍按各自真实条件触发，不因跳过教学而被自动完成或永久关闭；
- 高炉、炎坑、固定炼器阵和其他生产设施不会随重新开始自动出现，仍需玩家自行建设。

重置或重新开始替换当前流程状态，不把上一轮物资叠加到新的开局赠送资源上。若未来提供“删除全部数据”，该操作才恢复首次游戏的空仓与完整教学状态。

### 宅院与家具

玩家进入内门后获得宅院、纸质炼器阵及基础家具。床、蒲团、桌子和柜子等家具作为真实物品展示，并在可用状态下提供对应功能。

玩家可以将家具投入炼器阵归元。例如，将蒲团归元为木气后：

- 蒲团不再存在；
- 主动打坐功能不可用；
- 使用蒲团打坐时，灵气回复的当前讨论基线为每秒10点；
- 没有蒲团时，仍以每分钟1点的当前基线自然回复；
- 玩家可以通过重新制作蒲团恢复主动打坐。

界面不应只将“打坐”静默置灰，而应显示不可用的原因和仍在进行的自然回复。

### 家具功能基线

家具不是只用于表现的装饰图标。其功能来自物品实例及部署状态；被携带、收起、归元或摧毁后，对应能力也随之停止。无属性灵气参与的凡品家具不能由主角出售。

| 家具 | 当前功能基线 |
| --- | --- |
| 蒲团 | 主角打坐时每秒恢复10点灵气，适合前期少量、持续回气 |
| 床 | 主角睡眠30秒后一次性补满灵气；灵气上限进入数千后，替代固定速率的蒲团承担大额恢复 |
| 桌子 | 为纸质炼器阵提供平整的展开表面；宅院外使用阵图时也必须携带并部署桌子 |
| 柜子 | 存放实体配方和图纸，减少物品栏中的配方堆叠；不提供跨地点的自动搜索或额外生产能力 |
| 鸟笼 | 制成后部署在宅院一角并引来两只鸣叫的小鸟；主角心情愉悦，但亲自采集的耗时变为正常值的100倍 |

蒲团与床都属于独占主角的恢复行动。按当前基线，缺失灵气少于300点时蒲团更快，缺失300点时两者同为30秒，缺失超过300点后睡觉逐渐占优。最终恢复结算、能否中断及离线推进的交互仍待原型确认。

纸质炼器阵与桌子是部署依赖，不会合成为同一件物品。玩家在资源点携带阵图但没有可用桌子时，尝试展开应提示：

> 没有平整的地方摊开炼器阵卷轴。

柜子和鸟笼的配方可以在前期商店取得。柜子只改变配方物品的存放位置；鸟笼的惩罚只作用于主角亲自执行的采集循环，不降低傀儡、固定设施或物流线路的吞吐。鸟笼不再部署后，该耗时修正随之消失，避免装饰物造成不可恢复的流程阻断。

玩家进入内门后免费获得以下各一件下品工具：

| 工具 | 开局用途 |

| 铲子（下品） | 挖取泥土 |
| 木桶（下品） | 装载泥土或水 |
| 锯子（下品） | 砍伐树木 |
| 铁桶（下品） | 装载熔化的金属 |

初始工具是生产资料，不是跳出通用物品规则的教程特例。若玩家失去某件工具，应保留低效的徒手行动、当地取材、返回宅院或手工重制等恢复路径。

## 图纸、炼器与手作

### 图纸的作用

图纸记录器物的材料、所需工量与可用制造方式，不为同一器物分别创建“手作版”与“炼器版”两份物品定义。

- 宗门可以免费提供基础家具图纸。
- 商店可以出售花洒、铁镐、灵气驱动的冲击钻及作业傀儡等更高级器物的图纸或成品。
- 购买成品解决当下需求；购买图纸获得可重复制造、替换工具和扩展傀儡队列的长期生产能力。

### 正式配方表的生长方式

正式配方表尚未逐项编写，但每件器物的每个品级都要有对应配方；同品级、同器物可以有不止一条合成路线。任务解锁默认配方，并解锁所需的主材、材料配方与取得途径；玩家还可以在市集和藏经阁寻访替代配方及辅材配方。配方一经取得没有额外的理解门槛，但复杂配方所需的复合材料仍须经任务解锁。主线任务解锁的二元素主材作为各条体系化生产路线的起点，不为每种新材料另开一套独立体系。

材料的元素数按所含**不同属性**计算，而不是按投入件数计算。二元素材料可以由不同属性的基础材料与属性灵气组成，例如木头加金生灵气得到“剑锋木”；此时木头已经是从被金气所克的树木取得的材料，可以继续参与合成。也可以由两种不同属性的基础材料组成，例如金属加泥土制成耐火导流槽。同属性相加不算二元素材料，不设置“木头加木生灵气”这样的配方。导流槽由剧情推进并通过主线任务直接授予配方，属于主角的工业化独门器物，不在市场交易；制造时不需属性灵气，与运行时可能消耗火气是两回事。

三元素和四元素材料沿已解锁的二元素主材路线继续生长。五行中任选四种属性只有五种四元素组合，但同一组合可以有多条合成路线，例如：

```text
默认路线：（金生灵气＋木头）＋水生灵气 → 三元素材料；再＋泥土 → 四元素材料
替代路线：（金生灵气＋木头）＋（水生灵气＋泥土）→ 同一四元素材料
```

替代路线可以节省基础材料、节省属性灵气、减少工序，或提高单批次的目标产物数量；一条路线也可以同时具备多种优势。默认配方以复数下级材料产出1件更复杂的材料或器物；替代配方可以通过减少工序损耗，使同批投入产出2件、3件目标产物，具体投入、产出与泄漏均按该配方单次结算，不预设10件之类失控的单批产量。归元作为另一项独立操作，不追溯该物品实际采用的制造路线，也不以合成和归元循环的总收支限制高产配方；玩家可以利用循环净增下级材料。是否自制二元素材料或从市场采购也因此成为生产决策。二元素材料可大量生产和交易；后期玩家可以外购简单辅材，把阵法产能留给复杂材料的批量生产，但导流槽等明确不上市的独门器物除外。当前明确的五元素配方产物只有作为器物的空白灵石，尚未定义其他五元素材料。v1.0配方每次只产出一种目标物品，不设计副产物；同一种目标物品可以一次产出多件，多条配方路线可以分叉、汇合。

五行中不同属性组合的数量为二元素`C(5,2)=10`种、三元素`C(5,3)=10`种、四元素`C(5,4)=5`种。这是属性组合数，不是必须实装的材料或配方数。三元素可由已有二元素材料加入一种尚未包含的属性灵气或基础材料；对每组三元素属性，有`3×2=6`种接法，共60种。四元素可由三元素材料加入一种新属性，对每组有`4×2=8`种接法；也可由两种属性集合互不重叠的二元素材料组合，对每组有3种配对。因此每组四元素属性有11种候选接法，共55种。重复加入已有属性不增加元素数，例如「金木材料＋木头」仍只含金、木两种属性。候选接法是否成为正式配方，须由具体材料、投入与产出决定。

三元素、四元素的逐项默认配方和命名暂缓；先开发已确定的二元素材料与阵法系统基础，待模块能实际运转后再继续设计高元素材料内容。

器物本身也可以是进一步炼制的配方材料；可携带的炼器阵及家具同样遵守物品投入和库存规则。归元、淬炼或合成能否用于某件器物，仍由该器物已有工序决定，例如空白灵石没有归元方式。建成并固定在地点上的建筑物不能搬入炼器阵；其本体可以按规则升级，额外布设的阵法则可以拆下、更换或作为器物继续炼制。建筑、可携器物与部署状态的边界见[《建筑、地图与生产网络》](BUILDINGS_AND_LOGISTICS.md)。

### 逐级归元与材料返还

归元沿默认配方逆推一层：复合材料按元素构成逐层拆解，不能从五元素材料一步取得全部基础材料与属性灵气；基础材料可再按其自身归元规则转为对应属性灵气。材料没有品级；器物才有初级、中级、高级、天级等品级。高品级器物归元到低一品时固定返还1件低品级本体，其余投入按适用归元率返还，不将本体折算成不足1件。每次归元只结算当前投入及其明确的下一层产物，不自动继续归元，也不追溯原物品采用了默认还是替代配方。

| 当前投入的材料所含不同元素数 | 当次归元率 |
| --- | ---: |
| 基础材料（一元素） | 100% |
| 二元素材料 | 80% |
| 三元素材料 | 60% |
| 四元素材料 | 40% |
| 五元素材料 | 20% |

归元率先作用于该物品明确的下级材料与属性灵气返还量，但不削减器物归元时固定返还的1件低品级本体；**只有返还的属性灵气**再受炼器阵的灵气泄漏率影响，泄漏部分进入当地游离灵气，可由聚灵阵捕获，不能同时记入玩家持有量。下级材料只受归元率影响，不因阵法灵气泄漏再次扣减。基础材料的100%是归元本身的比例，不表示使用低效炼器阵就能取得100%的可持有灵气。九转阵用于恢复归元率，四象阵用于减少转化泄漏；两者作用不同。

例如剑锋木的默认配方投入金生灵气200点、木头2,000份。按二元素80%归元率，当次核算为金生灵气160点、木头1,600份；若所用炼器阵的灵气泄漏率为90%，玩家实际得到金生灵气16点和木头1,600份，其余144点金气进入当地游离状态。每件剑锋木都按同一归元规则结算；高产替代配方一次制得多件后逐件归元，允许获得超过该批制造投入的下级材料。这是可探索的生产路线，不按跨操作总守恒判作资源复制错误。

空白灵石和属性灵石均不可归元，也不能套用五元素20%归元率。可归元的其他五元素物品才使用该比例；复合材料的逐层返还清单随正式配方逐项确定。初级纸质炼器阵是特例：只能从内门藏经阁取得，没有制作配方；归元只返还五种属性灵气各100点，不返还基础资源，返还灵气仍按阵法泄漏规则结算。

旧稿针对“材料品级”的成本预算不再适用；材料仅按元素构成和具体配方区分，器物成本由其品级与正式配方逐项确定，不将旧预算直接转用为器物造价。

### 炼器制造

炼器以灵气代替人工劳动，主要付出材料、灵气和较短制作时间。

床的当前设计基线为：

```text
材料：木头 ×16
炼器灵气：200
炼器时间：1分40秒
```

该数值用于原型中比较制造方式，最终材料、灵气与工量仍需平衡验证。

### 手工制造

玩家可以按图纸使用材料手工组装器物。手工制造不依赖炼器阵，但必须遵守以下规则：

- 当前时间惩罚倍率为炼器时间的25倍；
- 手工制造独占主角，期间不能同时执行其他需要主角亲自完成的行动；
- 手工制造允许离线推进，与在线时使用同一套进度规则；
- 开始制作时一次性扣除全部配方投入；主动中断会清除进度、损失全部已投入材料且不产出成品，不能分段退料；
- 关闭页面或进入后台不视为主动中断，进度仍按离线规则推进；
- 只要携带了图纸所需材料，玩家可以在资源点手工制作蒲团等应急器物；
- 行囊容量因此同时制约可运回资源和可携带的应急材料。

按25倍计算，当前基线中手工制作一张床需41分40秒。该时间代表主角劳动的机会成本，不应成为可与采集、旅行、打坐并行的免费后台队列。

人工主持炼器阵允许暂停并保留已锁定的投入和进度；具备持续供灵的自动炼器队列则可在主角离开后继续运行。这两种状态不能套用手工制造的中断损失规则。主角自身灵气上限不限制可主持的阵法规模，可以分段输入灵气、打坐后继续；若使用聚灵珠中的外部储备，输入时优先消耗珠内灵气。功法依任务取得，配方没有额外理解门槛，高级配方所需的高级材料仍受任务解锁约束。

### 炼器阵的并行节点与驱动

纸质和固定炼器阵均可由主角亲自消耗自身灵气催动，并允许分段输入；具备持续属性灵气供应时也可自动运转。金、木、水、火、土各有一个属性节点，同一节点同一轮只处理一条配方；直接投入单一属性灵气的配方占用对应属性节点。二元素与三元素配方可以同轮运行，只要不争用同一节点。例如「土生灵气＋剑锋木」与「水生灵气＋地火」可以并行；前者与「土生灵气＋水」不能并行。除空白灵石中央凝结外，若以后有直接投入多种属性灵气的单条配方，其节点归属须随正式配方确定，不由界面自行推断。

不直接投入属性灵气的配方使用中央节点，例如不耗属性灵气的导流槽配方，以及「两种二元素材料→四元素材料」的合成。同一轮中央节点只处理一条配方，但可与属性节点同时运行。空白灵石虽然投入五种属性灵气，仍按既定中央凝结工序占用中央节点；配方材料所需的灵气与催动阵法所需的灵气分别记账。

| 炼器阵品级 | 同轮最多启用的属性节点 | 中央节点 | 六座同品级固定阵的并行配方上限 |
| --- | ---: | ---: | ---: |
| 初级 | 1 | 1 | 12 |
| 中级 | 2 | 1 | 18 |
| 高级 | 3 | 1 | 24 |
| 天级 | 5 | 1 | 36 |

主角亲自催动时，一轮所需的一份驱动灵气可以共同催动该轮启用的属性节点和中央节点，不按节点数重复收取；具体品级的每轮驱动数量尚待平衡。持续供灵时，属性节点使用对应属性灵气驱动，中央节点可由任意一种属性灵气驱动。同一份灵气不能既作为配方投入又作为驱动，或同时供给两个节点。节点的并行能力不改变每条配方各自的投入、产出、损耗、库存容量和制作进度。

## 基础材料与灵气转化

### 金属种类

游戏中的金属材料只有一种，统称为“金属”。不通过铜、铁、银或合金种类堆叠制造成长。

高阶器物的差异主要来自：

- 器物结构和图纸；
- 阵纹与工艺；
- 投入的属性灵气及组合；
- 供能、容量、效率与控制方式；
- 品级与具体功能。

矿石、金液和固态构件可以表示同一金属在不同处理阶段的形态，但不因此变成不同金属种类。

金液转运、铁桶凝固、泥土模具、水冷却、地火冷却和导流槽堵塞的共用规则见[《物资、储物与批处理》](MATERIALS_AND_STORAGE.md)。

### 纸质炼器阵基线

当前开局数值基线为：

- 主角初始持有100点灵气；
- 纸质炼器阵驱动一轮消耗50点灵气；
- 初始灵气因此最多连续驱动2轮；
- 转化不设最低投料量，1份基础资源也可以启动一轮；
- 初级炼器阵按当前10%效率结算，使用1,000份对应基础资源可以产生100点目标属性灵气；
- 灵气的最小单位为1，每轮产出独立向下取整，不保存或跨轮累积不足1点的隐藏余数；因此投入1至9份资源会得到0点灵气；
- 纯转化效率不得超过100%，驱动灵气、转化损耗和逸散必须真实记录。

开局首次投料100份泥土执行土生金时，纸质炼器阵消耗50点主角灵气，金阵眼得到10点金生灵气，未完成转化的90点土生灵气进入宅院的游离灵气状态。界面必须在玩家催动前显示预计产出，包括产出为0的情况；允许玩家确认低效操作，但不能把损失伪装成程序错误。

开局数值将在首个垂直切片中验证。若采集、搬运和转化总时长使安全路径失去可读性或趣味，应调整数值，而不用隐藏补贴绕过规则。

## 属性灵气与赋能

### 无灵石时的灵气用途

开局没有空白灵石可以保存容易逸散的属性灵气。玩家可以将刚产生的灵气立即用于：

- 赋能匹配的工具；
- 驱动后续转化或炼器工序；
- 支付其他明确的生产做功成本。

开局的首个关键反馈为：

```text
挖取泥土
  → 土生金，得到金气
  → 将金气赋予锯子
  → 砍伐工量显著提升
  → 快速获得木头
  → 制作水桶
  → 前往灵泉取水
```

### 工具赋能规则

- 赋能将属性灵气绑定到特定用途，不是可逆的通用储能。
- 已赋能灵气不得从工具抽取、转移或改作其他用途。
- 工具作业时按实际完成的工量消耗赋能。首个切片的金气赋能下品锯只按作业衰减，闲置时不衰减；其他工具的闲置逸散在对应原型中再定。
- 赋能只提高工作吞吐、降低可解释的作业损耗，或改变明确工序，不得从同一资源存量中凭空创造物质。
- 属性与工具效果应优先根据作业对象及五行关系决定，不为每个工具与灵气组合编写一套互不相干的特例。
- 界面使用无歧义倍率表示效果；“砍树效率`+1000%`”最终是指`10倍`还是`11倍`尚待确定。

首次教学中，10点金生灵气全部赋予下品锯后显示`+1000%`。首个切片闲置不衰减；每完成一次强化砍伐减少50个百分点，并在该次取得10份木头。赋能耗尽后，普通砍伐每次只取得1份木头。百分比是工具的赋能强度，不是允许存在半点灵气的另一种灵气单位。

首个垂直切片只需实现和验证“金气赋能下品锯”。其他工具与五种灵气的组合不得为了预留未来而提前扩展为大量空壳效果。

## 炼器阵品级与外围阵法

### 固定炼器阵的拓印与升级

固定炼器阵建成后留在原地点，不能拆下投入其他炼器阵；升级在原址完成，阵法本体延续为高一品。以下是未受六芒阵等效果调整的默认投入，五种属性灵石均指金、木、水、火、土各一份对应数量：

| 操作 | 默认投入 |
| --- | --- |
| 拓印初级固定炼器阵 | 泥土、木头、水各2,000份 |
| 初级升中级 | 五种基础材料各10,000份；下品空白灵石2,000块；五种下品属性灵石各200块 |
| 中级升高级 | 锋砂珠、生根珠、凝澜珠、炎纹珠各2,000件；中品空白灵石2,000块；五种中品属性灵石各200块 |
| 高级升天级 | 暂不规划；待三元素材料的配方与名称确定后再设计 |

中级升高级只使用四种二元素珠；泥土与同属性的土生灵气不能凑成第五种二元素珠。六芒阵降低固定炼器阵升级成本时，以表中的默认投入为计算基准，不改变固定建筑不可拆卸的规则。制作耗时和建设交互仍待原型确认。

### 转化与灌注的反向取舍

炼器阵的本职是炼器和五行转化，灌注空白灵石只是附带能力。品级越高，资源转化越高效，但直接灌注属性灵石时浪费越大：

| 炼器阵品级 | 转化损耗 | 灌注损耗 |
| --- | ---: | ---: |
| 初级 | 90% | 0% |
| 中级 | 75% | 20% |
| 高级 | 50% | 40% |
| 天级 | 20% | 60% |

高品炼器阵仍可凭借更大的处理批量、更高的空白灵石品级兼容和外围阵法完成高吞吐灌注；低品炼器阵也不会因升级而完全失去用途。界面必须分别展示转化损耗和灌注损耗，不能用一个含糊的“阵法效率”合并两者。

### 外围阵法组合

炼器阵外围可以布设四象阵、两仪阵、七星阵、九转阵、归一阵、三才阵、六芒阵和八方阵。八种阵法按此顺序由剧情主线取得配方。每种外围阵法最多布设一座，不要求整套阵法使用同一品级；例如允许中级八方阵与高级三才阵同时工作。外围阵法只作用于拓印在地面上的固定炼器阵，主角随身使用的纸质炼器阵不能获得加成。

聚灵阵与八种外围阵法的默认配方均为每批产出1座，不设副产物。初级阵法直接消耗表中数量的**每一种**基础资源和**每一种**属性灵气；升级时另消耗1座低一品的同种阵法，表中数量仍是每一种基础资源和每一种属性灵气分别所需的投入，不是五种合计。聚灵阵没有替代配方；其他阵法的替代配方尚未确定。

| 阵法（主线取得顺序） | 初级 | 中级 | 高级 | 天级 |
| --- | ---: | ---: | ---: | ---: |
| 聚灵阵 | 200 | 3,000 | 45,000 | 675,000 |
| 四象阵（1） | 400 | 8,000 | 160,000 | 3,200,000 |
| 两仪阵（2） | 800 | 16,000 | 320,000 | 6,400,000 |
| 七星阵（3） | 1,600 | 32,000 | 640,000 | 12,800,000 |
| 九转阵（4） | 3,200 | 64,000 | 1,280,000 | 25,600,000 |
| 归一阵（5） | 6,400 | 128,000 | 2,560,000 | 51,200,000 |
| 三才阵（6） | 12,800 | 256,000 | 5,120,000 | 102,400,000 |
| 六芒阵（7） | 25,600 | 512,000 | 10,240,000 | 204,800,000 |
| 八方阵（8） | 51,200 | 1,024,000 | 20,480,000 | 409,600,000 |

聚灵阵初级最多储存100点指定属性灵气，中级、高级、天级依次为1,000、10,000、100,000点；捕获速率另按地点规则结算。纸质炼器阵初级只能从内门藏经阁取得，没有制作配方；中级、高级、天级分别消耗低一品纸质炼器阵1张，以及五种基础资源和五种属性灵气**各**10,000、1,000,000、100,000,000。纸质炼器阵可以按器物规则逐级归元，初级的特殊返还见上文。

四象阵、两仪阵、七星阵、九转阵、三才阵、六芒阵的初级、中级、高级、天级，分别按`10%／25%／40%／60%`降低各自指定的目标量。效果和作用边界如下：

| 阵法 | 指定作用 |
| --- | --- |
| 四象阵 | 降低固定炼器阵五行转化时的灵气泄漏，提高该次转化效率；单次纯转化效率仍不得超过100% |
| 两仪阵 | 降低炼器配方要求的五种基础材料数量 |
| 七星阵 | 降低催动固定炼器阵所需的驱动灵气，不降低作为配方材料投入的属性灵气 |
| 九转阵 | 降低归元率相对100%的损失，恢复当次可返还的材料与灵气；不改变器物固定返还1件低品本体的规则 |
| 三才阵 | 降低固定炼器阵每轮运转耗时 |
| 六芒阵 | 降低固定炼器阵升级时的物资成本，不降低其他器物或外围阵法的制作成本 |

归一阵仅在**低一品属性灵石替代高一品属性灵石用于固定炼器阵功能供能**时生效：初级、中级、高级、天级分别把每1块高品灵石所需的低一品灵石从16块降到14、10、7、4块。不改变市场兑换、配方投入、建设需求或纸质炼器阵供能的`16:1`规则，也不生成可库存的高品灵石。

八方阵允许固定炼器阵跨地图使用资源点聚灵阵已吸纳的属性灵气。初级、中级、高级、天级的远程传输损耗依次为`75%／50%／25%／0%`；接收端只能使用扣除损耗后的实际到达量，损耗不能同时记入两地库存或供能。连接、分流和接收仍须具备明确状态，不能任意读取所有聚灵阵库存。

成本降低按以下顺序结算：

```text
调整后需求
= max(配方规定的不可降低下限,
      ceil(基础需求 × (1 - 降低比例)))
```

离散材料的最低需求至少为1。外围阵法不能在同一次纯转化中把40份金属直接变成100份金属。高产合成与后续归元是独立操作，不以整条循环的净产出作为配方下限。若多个效果共同作用于同一损耗通道，按剩余损耗乘算，避免负损耗和单次纯转化超过100%的利用率：

```text
最终损耗
= 基础损耗 × ∏(1 - 各阵法降低比例)
```

## 灵石生产、替代与供能

### 下品属性灵石构成

下品空白灵石与属性灵石的当前结构讨论基线为：

```text
下品空白灵石
= 金、木、水、火、土灵气各100

下品属性灵石
= 下品空白灵石 ×1
+ 目标属性灵气 ×100
```

例如，下品木灵石包含金、水、火、土灵气各100，木灵气200。按初级炼器阵当前`1000 → 100`的转化基线，若完全以基础资源人工生产，共需要五种基础资源各1000，以及目标属性对应的额外1000，合计6000份基础资源。空白灵石无法归元，因此商店对空白灵石的低价批量供应不会让玩家直接取回其形成时使用的五行灵气。

强行在自动化之前手工生产灵石是允许的低效路径，不应设置与世界规则无关的硬性禁止。该路径即使作为挑战玩法，也必须被正确结算并能够存档、离线推进与恢复，但不应通过强力奖励将其变成标准最优路径。

### 空白载体与永久稳定

空白灵石不是M02的第六种基础资源，而是M07拥有、由五行灵气凝结而成的器物。它可以灌注、封灵、储存、运输、交易并用于后期灵脉采掘，但没有归元方式。界面不显示“无法归元”，只是不提供该操作。

属性灵石完成灌注和封灵后永久稳定，不随时间逸散、降品或产生维护成本。同属性、同品级灵石可以按数量堆叠，不记录每块灵石的剩余能量。

属性灵石作为供能物时，一旦提交给阵法、傀儡或其他接收端便不可取回。供能不产生可以重新放回库存的“半块灵石”，也不允许高品灵石只释放一部分去适配低品器物。工序中断时已经提交的灵石如何损失或继续结算，留待对应供能原型确定。

### 高低品级替代

不同品级的阵法、傀儡和炼器配方可以要求对应品级的同属性灵石。玩家缺少目标品级时，可以用低一品灵石按`16:1`替代：

```text
下品属性灵石 ×16 → 替代中品同属性灵石 ×1
中品属性灵石 ×16 → 替代上品同属性灵石 ×1
上品属性灵石 ×16 → 替代天品同属性灵石 ×1
```

跨多个品级时逐级连乘，因此1块天品灵石需求可以由4096块同属性下品灵石替代。替代只在配方、建设或供能的当前提交中满足需求，不会生成一块可以带走的高品灵石。高品灵石不能向下替代低品需求；低品器物无法承受高品灵石，也不存在取出部分能量延长续航的操作。

同一批需求允许混合使用目标品级和低品替代。例如需要3块中品火灵石时，可以提交2块中品火灵石与16块下品火灵石。多属性需求分别校验，数量不足时整笔操作失败，不进行部分扣除。

只有固定炼器阵的功能供能需求可受归一阵影响，按归一阵品级改用`14:1／10:1／7:1／4:1`的相邻品级低品灵石提交比例；配方、建设、其他器物供能及市场兑换仍各按原规则结算。归一阵改变的是该笔供能的替代数量，不降低目标品级灵石本身的需求，也不改变底层`16:1`标准成本核算。

空白灵石、品级压缩、阵法灌注上限和灵脉采掘阵的详细规则见[《物资、储物与批处理》](MATERIALS_AND_STORAGE.md)。

## 交易、价格与灵石面额

属性灵石是标准化、易运输的生产资料和宗门硬通货。所有实际成交的最低价格为一块任意属性下品灵石，不存在零灵石成交或灵石小数；即使普通家具的实际价值远低于一块下品灵石，NPC仍可能挂出“一块下品灵石购买一件家具”的一次性坑人销售单。低价物品可以通过成套出售或批量委托改善面额问题，但首个可玩切片不建立另一种通用小额货币。

当前设计方向为：

- 五种基础资源不在市场出售，主角也不能出售它们；空白灵石作为M07器物可以交易，当前批量价格基线为任意下品属性灵石一块购买下品空白灵石1000块；
- 完整生产链没有属性灵气参与的物品是凡品，主角不能出售；这包括自制家具、普通工具、导流槽、传送带和天索。NPC仍可向玩家出售家具等凡品，其中坑人销售单只出现一次；
- 完整生产链有属性灵气参与的材料和器物可以由主角出售；
- 商店可以将花洒、工具与耗材组成整套生产资料，再以灵石结算；
- 批量委托可以在交付多件商品后统一支付一块或多块灵石；
- 高级成品和可重复生产的图纸可以直接以灵石计价；
- 整体市场的货源和需求在当前版本视为无限；单个商人可以接收玩家的大批供货，但会通过隐藏的大宗议价系数压低单件收购价，不建立全市场供需波动；
- 紧急需求、特定人物、批量采购和限时委托可以产生高于平时的价格。

### 标准灵气成本与价格边界

物品的隐藏估值沿**默认配方的完整材料链**向前追溯，累计制造所需各级材料对应的五种属性灵气，再统一折算为下品属性灵石数量。金属、木头、水、火和泥土的投入数量不计入该估值；玩家亲自供应的灵气不从标准成本中扣除。估值使用未经外围阵法、生产者技术和实际损耗修正的默认配方链，而不是玩家实际选用的廉价路线；否则技术降本会反过来压低同一成品的标准价值。

配方链直接消耗的属性灵石也计入标准成本。底层统一以同属性相邻品级`16:1`折算为下品灵石当量：1块中品、上品、天品分别记为16、256、4,096块同属性下品灵石。这个比例只用于成本核算与投入替代，不是市场兑换价；给NPC显示报价或派发交易款额时，才按相邻品级`12:1`的市场向上兑换比例换算面额。多属性成本分别记账，报价可以同时列出多种属性、品级和数量；五种同品级属性灵石在价值换算中始终`1:1`，但NPC可以拒绝玩家提出的异属性等值替代，报价或成交确认前须明确接受哪些属性。将计算值落实为灵石数量时只保留整数部分，直接舍去小数，不四舍五入；例如`2.9`块按`2`块计，最终实际成交仍受最低一块下品灵石的限制。

支付和兑换分开结算。若报价为中品火灵石8块、中品木灵石6块，玩家可以用上品火灵石1块和上品木灵石1块付款：高品支付低品需求按同属性相邻品级`1:8`抵价，火系正好付清，NPC须找回中品木灵石2块。若用下品支付中品需求，按市场向上`12:1`，分别需要下品火灵石96块、下品木灵石72块。各属性分别核算，不能默认把一种属性的多付款抵扣另一属性；NPC明确接受异属性等值替代时才可这样支付。NPC收取高品面额并产生超额时负责按报价属性找零，不吞没差额。灵石兑换处也按向下`1:8`、向上`12:1`兑换：1块上品木灵石只能换8块中品木灵石，再换回1块上品需要12块中品木灵石。先降品再购物与直接付上品后找零在同一报价下等价，不产生额外套利。

例如某物品的标准配方消耗五种属性灵气各50,000点，并另耗用100万份基础资源；基础资源不进入估值，按下品属性灵石每块对应100点目标属性灵气的当前基线，其10倍最高成交估值为五种下品属性灵石各5,000块。

NPC对一件物品的最高成交估值为标准灵气成本的10倍。玩家挂牌不受这一上限限制，可以标出任意离谱但不低于最低面额的价格；超过NPC支付意愿的挂牌不会被系统强行禁止，只是不会有NPC成交。

NPC商人出售物品时，隐藏的最低可接受价格为标准灵气成本的2.5倍。初始报价可以受商人当前报价策略、关系、人物性格和单笔数量影响，玩家能够砍价，但低于隐藏底价时NPC拒绝。界面不公开公式和准确底价，可以通过对话反馈让玩家判断对方是否仍有让价空间。

NPC发布的炼器采购任务，报酬范围为标准灵气成本的0.1倍至4倍；最终离散支付仍不得低于一块任意属性下品灵石。低倍率委托可以体现宗门对新人的压价，却不保证后续回报：某些任务会在很久之后才触发同一NPC的新任务，甚至当下看起来只是一次性委托，接取前不会许诺或透露隐藏后续。替代配方与外购材料可能让低倍率任务也有利润。设计目标是让玩家逐渐形成模糊的成本判断，而不是要求每次交易都精算完整材料链。

### 任务接取、整批交割与保证金

- 只有主线任务强制获取且没有完成时限；其他任务由玩家自愿接取，均有完成时限，接取时可以要求保证金。
- 首阶段只开发NPC发布的额定交付任务：交付数量、截止时间和报酬固定；不开放议价、延长交期、提高报酬、低品抵高品、提前交付、分期交付或转包其他宗门弟子。游戏没有残次品或良率概念。
- 玩家接取时指定交割地点及该地点的仓储设施，并可设置到交割期自动提交。交割时只检查所指定仓储设施中的合格物品；不从主角行囊、其他仓库、设施输入槽或运输途中的货物自动拼凑。
- 交割先检查供货方在指定仓储中是否备齐整批合格物品；缺一件就按供货失败结算，不检查采购方货款。只有供货齐备，才检查采购方能否付款；双方都满足条件时，一次性交换全部货物与货款，不部分扣货或部分给钱。交割前货物不预留，玩家可以卖掉或挪用，但必须承担到期库存不足的后果。市场购得的合格物品也可以用于交割，来源不受限制。
- 周期性任务可以设置自动接取、自动化批量生产和到期交割。供货方的保证金接取时锁定在任务上，跨成功周期沿用，确定不接下一期时返还；交货失败则归采购方。任何一期交割失败后，右侧任务面板高亮闪烁提示失败，自动接取暂停，等待玩家处理，不直接接下一个周期。再次接取时按当时信用重新核算实际应缴金额，并在接取前展示。

### 主角发布采购与双向履约

三元素材料解锁后，主线也应让主角习得中级炼器术，并将灵气上限提升至1,000。此时主角可以作为采购方发布材料求购或代工任务，设定报价、供货方保证金比例和交货时限，与愿意接单的NPC议价；NPC也可以要求主角提高报酬。它仍沿用整批、到期、指定地点与仓储设施的交割规则：NPC交来的货自动进入玩家指定仓储，可以据此设置周期性补货。正常信用下主角发布采购任务不预扣或锁定货款；曾到期无款而仍处于惩罚考察期时，须先预缴当笔报价的50%定金。无属性灵气成本的独门器物如导流槽不进入这一市场采购体系。

交割期按“先验货、后验款”的固定顺序区分两类违约，不能都写成“任务失败、没收保证金”：

| 到期状态 | 货物与货款 | 供货方保证金 | 采购方预缴定金 | 后果 |
| --- | --- | --- | --- | --- |
| 双方履约 | 整批交货并付清约定货款 | 退回供货方；自动续期可继续锁定 | 如有预缴，抵扣应付货款，不额外收费 | 双方相应信用账各记一次成功 |
| 供货方缺货或未交齐，不论采购方是否有款 | 不交货、不付款；跳过尾款检查 | 转交采购方 | 如有预缴，退回采购方 | 只记供货方违约；采购方不记失败 |
| 供货齐备，但采购方无法支付尾款 | 不交货、不支付尾款；货物仍属供货方 | 退回供货方 | 如有预缴，转交供货方 | 供货方按已备齐货物记履约成功，采购方记付款失败，任务终止 |

采购方既可能是玩家，也可能是NPC。若双方同时缺货、缺款，任务只按供货失败处理：采购方即使付不起钱，也因未进入付款环节而不受信用惩罚，并取得供货方保证金；已预缴的采购定金退回采购方。只有在供货齐备后查出采购方到期无款，才认定采购方违约；此时不形成欠债、补款或延期交付记录。NPC是否会付款也可以由任务内容与人物性格明确设定，例如压价委托的采购NPC可能必然在交割时无款，而不是假定所有NPC拥有可模拟的完整钱包。供货方保证金和采购方定金分别绑定任务锁定，不能被NPC额外侵占；采购方违约时不得没收供货方保证金。不同人物可以用剧情模板回应违约。

### 双信用账、惩罚与任务触发

玩家作为供货方的履约信用，与作为采购方的付款信用，是两本独立的隐藏账。供货失败只改变供货账，采购无款只改变采购账；另一身份的成功也不能代替本身份消除惩罚。供货信用好但采购信用差的玩家可以同时存在。只在对应身份到期履约结果明确时更新该账；交割前拒绝任务不计失败。

供货账记录全局保证金惩罚比例`p`，初始为`0`。每次到期缺货，`p`增加`0.5`；每次按期备齐整批合格货物，`p`减少`0.2`，最低为`0`。后续所有新接的供货订单根据各自货款与原定保证金比例计算基础保证金，再乘以`1+p`；实际保证金不得超过该订单货款总额。惩罚比例跨订单叠加，不把某张订单的固定保证金永久抬高；已接订单锁定的金额不因信用变化追溯改价。例如基础保证金为100，失败一次后新单需150，之后连续三次成功，后续新单依次需130、110、100。失败时当次已锁保证金真实转交采购方；惩罚主要提高后续订单占用的流动资金，有足够财力的玩家仍可继续接单。

采购账分别记录报价倍率`m`与定金考察期剩余成功次数`c`，初始为`m=1`、`c=0`。首次到期无款使后续同条件订单在正常报价之外再增加200%的惩罚，即`m=3`，并使`c`增加7。再次到期无款时，按违约当时的报价倍率重新乘2，即`m←2m`，同时使`c`在当前剩余次数上再加7，不把剩余次数翻倍，也不重置已完成的成功次数。每次到期验货后成功付清货款，`m`减去正常报价的`0.3`倍，最低为`1`；`c`减少1，最低为`0`。`c>0`时须预缴当笔报价的50%定金，该比例在整个考察期不递减；成功支付时定金抵款，再付余款，`c=0`后才撤销后续订单的定金要求。报价惩罚与定金考察期分别结算，不要求在同一笔订单同时归零。若正常报价为100，首次违约后后续报价为300；成功付款三次后倍率为`2.1`、考察期余4次，此时再违约，后续报价倍率为`4.2`、考察期余11次。

两本账分别记录连续成功与连续失败的任务数；成功打断本账的失败连击，失败打断本账的成功连击，不影响另一本账。只有供货惩罚`p=0`，或采购倍率`m=1`且考察期`c=0`，才开始累计本账的“极好信用”连续成功任务。供货账和采购账各自在极好信用连续成功`25／50／100／200`单时触发一组大额奖励任务；各自在连续失败`50／100／200／500`单时触发一组大额坑人任务。两组奖励、两组坑人任务，共16个门槛触发点；具体任务、奖励和陷阱程度等M09基础搭建后再规划。

NPC记得自己发布的任务被接取、拒绝、完成或失败；拒绝不算供货失败。具体人物性格可以决定是否再次发布同一任务、每次小幅加价以及后续叙事，不要求提前向玩家解释隐性收益。

交割前能否改换指定仓库、周期频率、任务触发门槛能否在同一周目重复领取，以及具体奖励和陷阱内容尚未确定，不由实现自行补全。任务生命周期与双信用账由M09负责，库存扣除由M06的真实仓储边界处理，灵石支付和找零按M07、M08的契约结算。

### 兑换、替代与套利

属性灵石的市场兑换继续采用同属性向上`12:1`、向下`1:8`的不对称比例。它与配方及供能中的`16:1`低品替代不同：市场兑换产生可以储存和交易的高品或低品灵石，替代只满足当前提交。

在正式配方表形成后，应使用统一脚本从标准灵气成本批量计算基准价格，并检查购买、分解、制造、交易和品级兑换形成的经济路径。技术、地点、库存、委托、时间和关系造成的有界套利是正式玩法；同一地点以固定价格和无限库存反复执行、没有决策和机会成本的封闭获利循环属于缺陷。

## 首个可玩闭环

### 首次开场与界面展开

首次游戏按以下顺序建立世界、界面和操作语法：

1. 游戏加载后依次显示“金、水、木、火、土”，组成以圆盘为背景的五角星，随后出现“炼器宗 / Refining Sect”标题。
2. 标题上移并缩小到置顶窄Banner；五行圆盘缩小到粗糙卷轴上的纸质炼器阵，卷轴外出现剧情对话框，交代主角在外门大比取得前十、依规进入内门。
3. 纸质炼器阵图标移向左侧并展开背包栏，剧情框移向右侧并展开功能栏；中央显示一进四合院式的筑器峰114514号宅院，并说明将阵图拓印到中央空地后即可成为见习炼器师。
4. 背包栏显示免费工具、下品行囊和“设施”栏中的宅院家具，但不提供基础资源；右侧显示“剧情”“地点”“动作”“任务”栏位。
5. 背包下方显示主角灵气`100`。剧情要求玩家把纸质炼器阵放到桌上展开。
6. 教程用箭头明确指示：点击纸质炼器阵，点击“设施”，再点击桌子。
7. 中央展开纸质炼器阵，阵眼可点击查看信息；“地点”栏首次只显示泥沼。

### 初次采土与土生金

8. 玩家前往泥沼时不产生旅行时间，场景切换到山间泥潭。
9. 玩家点击木桶将其拿在手中，再点击泥潭开始装土。下品木桶容量为10，装满后停止；玩家点击行囊，将桶中泥土倒入行囊。该过程重复至行囊携带100份泥土。
10. 剧情提示返回宅院，使用主角自身灵气催动纸质炼器阵。
11. 回到宅院后纸质炼器阵展开。玩家打开行囊，点击泥土后一次取出全部100份，放到土阵眼，再从“动作”栏选择“催动炼器阵”。首轮原型以10秒持续消耗主角50点灵气；阵图显示运转动画，累计消耗50点后停止，金阵眼出现10点金生灵气。
12. 剧情指出纸阵只有约一成效率，画面顶部显示本区域“土生灵气 90”，明确表现转化损耗已经泄漏到环境。
13. 主角决定向内门藏经阁长老询问提高效率和处理泄漏的方法，自动获得主线任务“去内门藏经阁求教”。
14. 模拟时间暂停。剧情说明刚产生的灵气若不及时使用，会在5息后开始消散；教程指示玩家全量拿起金阵眼的金生灵气并放到锯子上完成赋能。暂停期间所有模拟倒计时一并停止。

### 赋能砍树、储料与取水

15. 锯子显示`+1000%`并开始随时间衰减。模拟时间恢复，剧情要求玩家赶往新显示的丛林；场景切换到椰树林。
16. 游戏不再逐步指示砍树操作。赋能锯每次取得10份木头并额外降低50个百分点；金气使用过程产生的最小单位逸散会使区域顶部金生灵气在1与0之间出现变化。赋能归零后，继续砍树每次只能取得1份木头。
17. 返回宅院后，教程引导玩家把行囊中的木头存入柴房。剧情揭示拓印初级固定炼器阵需要泥土、木头和水各2,000份。
18. “任务”栏显示第二个主线任务“积攒足够数量的基础资源”，并分别显示三种材料的`当前数量 / 2,000`。
19. 剧情提示木桶同样能够装水，“地点”栏显示灵泉；玩家点击后切换到泉眼场景。
20. 游戏不再限制取水次数，首次操作教学在此结束。此后由任务、事件和进度逐步揭示地点与机制，不再持续使用强制箭头规定操作顺序。

### 教学后的首个工程目标

初级固定炼器阵的拓印配方为：

```text
泥土 ×2,000
木头 ×2,000
水   ×2,000
```

首次游戏从空仓开始取得全部材料；重置或通关后重新开始时，三种材料各有1,000份开局库存，但仍需补足另外一半。高炉和炎坑不属于拓印奖励，仍由玩家在后续流程自行兴建。

首个垂直切片应以以下玩家流程为主线：

```text
获得宅院、纸质炼器阵和内门初始工具
  → 在首次操作教学中把纸质炼器阵铺到桌面
  → 前往泥沼，以初始木桶和行囊取得100份泥土
  → 使用纸质炼器阵执行土生金
  → 看见10点金气与90点泄漏土气
  → 将刚产生的金气赋能下品锯
  → 以明显更高的吞吐砍伐树木
  → 将木头存入宅院柴房
  → 携带木桶前往灵泉按容器容量取水
  → 使用木头按图纸手工制造额外木桶，首轮原型耗时400秒
  → 保存进度并在刷新后继续
```

首个切片只需实现完成上述闭环所需的最小规则。灵石生产、高级工具、傀儡、商店完整结算和自动化网络只作为当前规则的后续方向，不纳入首个切片实现范围。

## 首个切片的验收不变量

- 玩家无需开发者口头指引即可找到至少一条通往灵泉取水的可行路径。
- 首次游戏、重置游戏和通关后重新开始能够稳定选择各自的初始库存、地点显示和教学提示状态；跳过教学不会阻断后续任务与剧情。
- 纸质炼器阵允许任意正整数投料，并按每轮独立取整；重复投入不足产出1点灵气的小批次不能通过隐藏余数获得额外产出。
- 泥土与水的采集、携带和运输受木桶等容器的数量与容量约束，不退化为无容器的单点点击收集。
- 主角每次点击手工采集只立即结算一次；木桶容量和工具、灵气赋能效果真实生效，不因动画帧率额外产出。
- 将蒲团、家具或关键工具归元后，功能和恢复路径与文档规则一致。
- 手工制造开始即扣除全部投入，主动中断全部损失；期间主角不能另外执行亲力行动，关闭页面后仍按相同速度推进。
- 金气赋能锯子只改变可解释的砍伐工量或损耗，不凭空增加资源点总物质。
- 游离灵气、工具赋能和资源变化可以由真实模拟快照解释，不由动画帧率或界面特例决定。
- 在纸质炼器阵的低效转化和驱动成本下，手工冲击灵石不是无成本或明显最优的开局策略。
- 保存、刷新和离线返回不会丢失功能物品、制造进度、赋能余量、游离灵气或已产生的资源变化。

## 待验证与待定事项

以下问题尚未因本文档定稿：

- 主角的灵气上限、一次完整打坐的结算方式，以及200点炼器成本如何跨越当前灵气持有量；
- 床与蒲团能否中断、睡眠完成前是否产生部分恢复，以及恢复行动的离线结算交互；
- 其他工具赋能的容量、绑定效率、每单位工量消耗和闲置逸散速度；首个切片的锯子闲置不衰减，后续可据试玩再调整；
- 金气赋能下品锯的最终倍率及无歧义界面文案；
- 功能物品在库存、宅院安置、携带和装备状态之间的具体切换成本；
- 床、蒲团、花洒、铁镐、冲击钻和各类傀儡的最终配方与工量；
- 灵石提交供能后遇到工序中断、设施损坏或输入锁失效时的最终结算；
- NPC选择初始报价属性与面额的具体策略，以及是否接受玩家提出的异属性等值支付；
- 普通商品的成套规模、大宗议价系数和不同商人的报价差异；
- 当前早期物品造价讨论稿的最终材料、图纸价格、炼器耗能、制作耗时与手作工量；
- 下品聚灵珠的容量、重复使用规则、灌注与取用方式、损耗和溢出处理。

上述项目应通过首个垂直切片、后续对应玩法原型或单独设计决定逐项确认，不得在实施中默认补全。
