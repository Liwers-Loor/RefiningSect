# 《炼器宗》玩法基础规则

## 文档目的

本文档记录《炼器宗》首个可玩闭环及后续生产成长共用的玩法规则，回答玩家可以做什么、资源如何转化、功能物品如何生效，以及错误选择如何恢复。

本文档与现有权威文档的分工如下：

- [ROADMAP.md](ROADMAP.md) 定义各阶段向玩家承诺什么；
- [MODULES.md](MODULES.md) 定义规则、状态与跨模块协作由谁负责；
- [VERSIONING.md](VERSIONING.md) 定义页面版本号的生成与递进方式；
- [MATERIALS_AND_STORAGE.md](MATERIALS_AND_STORAGE.md) 定义物资语言、材料状态、嵌套储物、批处理与空白灵石；
- [BUILDINGS_AND_LOGISTICS.md](BUILDINGS_AND_LOGISTICS.md) 定义地点、建筑、本地仓储、灾害、聚灵阵与跨地点生产网络；
- 本文档定义跨模块玩法如何在玩家面前成立。

本文档不是完整配方表、最终数值表或内容制作清单。尚需原型验证的数值使用“当前基线”或“待定”标记，不得在实施时将示例自动解释为最终平衡结论。

## 设计原则

### 启发式教程

- 首次游戏使用一次明确的操作教学，通过箭头、聚焦和暂停帮助玩家完成摆放阵图、装土、转化与首次赋能；操作教学结束后，不再持续规定唯一正确顺序。
- 机制教学保持启发式：玩家应通过物品功能、资源变化、行动结果和世界反应理解规则，后续新信息可以只以`!`提示有新消息。
- 不告诉玩家“应当怎样做”，不等于隐瞒物品的当前功能、操作代价或不可逆后果。
- 玩家应能选择低效、奇怪甚至自我惩罚的路径，只要该路径遵守世界规则并保留恢复手段。
- 重置游戏或通关后重新开始时，操作教学默认关闭，但任务、剧情事件和实际规则仍然正常运行。

### 劳动方式成长

成长不只是同一动作的数值变大，也要改变谁在劳动、使用什么驱动、是否必须由主角在场，以及资源如何运输。

```text
徒手与基础工具
  → 属性灵气赋能工具
  → 灵气动力工具
  → 作业傀儡
  → 固定采集与加工设施
  → 端到端自动化网络
```

自动化不是执行某项生产的许可证。玩家原则上可以用人力完成底层流程，自动化的价值是将不可持续的人工劳动变成稳定工业。

### 主角行动与即时采集

主角在任何阶段都只有一个亲力行动位，不随境界或版本增加。打坐、睡觉、亲自催动炼器阵、转化与灌注等灵气相关行动由主角完成；交易、前往藏经阁取得功法等非专属事务可以交给傀儡。打开纸质炼器阵的操作面板时，主角只能执行该面板允许的阵法操作，不能同时挖土、取水或砍树；批量队列具备持续供灵后，阵法可以独立运行，主角才可离开面板做别的事。查看任务、剧情和库存等信息本身不占用行动位。

手工采集是一次点击、一次立即结算的原子动作，没有持续进度和取消操作。容器满时不能继续装入；容器品级只提高容量，不因容量变大而提高单次采集量。铲子、其他辅助工具或相应灵气赋能可以提高单次采集效率。采集量、容器剩余空间与资源变化仍由模拟规则结算，不由动画帧率决定。

### 真实结算与可恢复性

- 物品、工具、家具和设施的功能必须来自真实状态，不是界面中不受模拟约束的开关。
- 玩家主动归元、出售或耗尽功能物品时，其提供的能力会真实消失。
- 失败和错误决策可以造成明显的时间、效率与机会成本，但不得使核心流程进入不可恢复的软锁。
- 所有持续行动、工作进度、灵气逸散和离线推进都使用同一套确定性规则。

## 开局状态与功能物品

### 首次游戏与重新开始

首次游戏承担完整的新手引导。宅院中的土堆、柴房和水窖均为空，玩家没有任何基础资源，需要按剧情前往泥沼、丛林和灵泉建立第一批库存。

玩家从进入游戏起即可使用“重置游戏”。该入口既允许玩家主动跳过初期教学，也用于开发阶段反复测试剧情流程，不要求先完成某个教学节点。

重置游戏或通关后重新开始时使用以下基线：

- 土堆预置泥土1,000份；
- 柴房预置木头1,000份；
- 水窖预置水1,000份；
- 所有资源地点立即显示并可以前往；
- 操作教学提示默认关闭；
- 后续任务、事件和剧情仍按各自真实条件触发，不因跳过教学而被自动完成或永久关闭；
- 高炉、炎坑、固定炼器阵和其他生产设施不会随重新开始自动出现，仍需玩家自行建设。

重置或重新开始替换当前流程状态，不把上一轮物资叠加到新的开局赠送资源上。若未来提供“删除全部数据”，该操作才恢复首次游戏的空仓与完整教学状态。

### 宅院与家具

玩家进入内门后获得宅院、纸质炼器阵及基础家具。床、蒲团、桌子和柜子等家具作为真实物品展示，并在可用状态下提供对应功能。

玩家可以将家具投入炼器阵归元。例如，将蒲团归元为木气后：

- 蒲团不再存在；
- 主动打坐功能不可用；
- 使用蒲团打坐时，灵气回复的当前讨论基线为每秒10点；
- 没有蒲团时，仍以每分钟1点的当前基线自然回复；
- 玩家可以通过重新制作蒲团恢复主动打坐。

界面不应只将“打坐”静默置灰，而应显示不可用的原因和仍在进行的自然回复。

### 家具功能基线

家具不是只用于表现的装饰图标。其功能来自物品实例及部署状态；被携带、收起、出售、归元或摧毁后，对应能力也随之停止。

| 家具 | 当前功能基线 |
| --- | --- |
| 蒲团 | 主角打坐时每秒恢复10点灵气，适合前期少量、持续回气 |
| 床 | 主角睡眠30秒后一次性补满灵气；灵气上限进入数千后，替代固定速率的蒲团承担大额恢复 |
| 桌子 | 为纸质炼器阵提供平整的展开表面；宅院外使用阵图时也必须携带并部署桌子 |
| 柜子 | 存放实体配方和图纸，减少物品栏中的配方堆叠；不提供跨地点的自动搜索或额外生产能力 |
| 鸟笼 | 制成后部署在宅院一角并引来两只鸣叫的小鸟；主角心情愉悦，但亲自采集的耗时变为正常值的100倍 |

蒲团与床都属于独占主角的恢复行动。按当前基线，缺失灵气少于300点时蒲团更快，缺失300点时两者同为30秒，缺失超过300点后睡觉逐渐占优。最终恢复结算、能否中断及离线推进的交互仍待原型确认。

纸质炼器阵与桌子是部署依赖，不会合成为同一件物品。玩家在资源点携带阵图但没有可用桌子时，尝试展开应提示：

> 没有平整的地方摊开炼器阵卷轴。

柜子和鸟笼的配方可以在前期商店取得。柜子只改变配方物品的存放位置；鸟笼的惩罚只作用于主角亲自执行的采集循环，不降低傀儡、固定设施或物流线路的吞吐。鸟笼不再部署后，该耗时修正随之消失，避免装饰物造成不可恢复的流程阻断。

### 内门初始工具

玩家进入内门后免费获得以下各一件下品工具：

| 工具 | 开局用途 |
| --- | --- |
| 铲子（下品） | 挖取泥土 |
| 木桶（下品） | 装载泥土或水 |
| 锯子（下品） | 砍伐树木 |
| 铁桶（下品） | 装载熔化的金属 |
| 精碳导管（下品） | 导流地火；精碳在材料语义上即石墨 |

初始木桶提供第一份容器容量，使泥土和水以容器为单位被装载与运输，而不是让玩家空手每次只取得1份资源。玩家在首个闭环中仍会按图纸制作额外木桶：这既验证首次成器，也增加后续搬运水和泥土的吞吐。“初始持有木桶”与“制作木桶”因此不互相排斥。

初始工具是生产资料，不是跳出通用物品规则的教程特例。若玩家失去某件工具，应保留低效的徒手行动、当地取材、返回宅院或手工重制等恢复路径。

## 图纸、炼器与手作

### 图纸的作用

图纸记录器物的材料、所需工量与可用制造方式，不为同一器物分别创建“手作版”与“炼器版”两份物品定义。

- 宗门可以免费提供基础家具图纸。
- 商店可以出售花洒、铁镐、灵气驱动的冲击钻及作业傀儡等更高级器物的图纸或成品。
- 购买成品解决当下需求；购买图纸获得可重复制造、替换工具和扩展傀儡队列的长期生产能力。

### 正式配方表的生长方式

正式配方表尚未逐项编写，但每件器物的每个品级都要有对应配方；同品级、同器物可以有不止一条合成路线。任务解锁默认配方，并解锁所需的主材、材料配方与取得途径；玩家还可以在市集和藏经阁寻访替代配方及辅材配方。配方一经取得没有额外的理解门槛，但高阶配方所需的高阶材料仍须经任务解锁。主线任务解锁的二元素主材作为各条体系化生产路线的起点，不为每种新材料另开一套独立体系。

材料的元素数按所含**不同属性**计算，而不是按投入件数计算。二元素材料可以由不同属性的基础材料与属性灵气组成，例如木头加金生灵气得到“剑锋木”；此时木头已经是从被金气所克的树木取得的材料，可以继续参与合成。也可以由两种不同属性的基础材料组成，例如金属加泥土制成耐火导流槽。同属性相加不算二元素材料，不设置“木头加木生灵气”这样的配方。导流槽由剧情推进并通过主线任务直接授予配方，属于主角的工业化独门器物，不在市场交易；制造时不需属性灵气，与运行时可能消耗火气是两回事。

三元素和四元素材料沿已解锁的二元素主材路线继续生长。五行中任选四种属性只有五种四元素组合，但同一组合可以有多条合成路线，例如：

```text
默认路线：（金生灵气＋木头）＋水生灵气 → 三元素材料；再＋泥土 → 四元素材料
替代路线：（金生灵气＋木头）＋（水生灵气＋泥土）→ 同一四元素材料
```

替代路线可以因配方投入与工序损耗不同而显著降本，是否自制二元素材料或从市场采购也因此成为生产决策。二元素材料可大量生产和交易；后期玩家可以外购低阶辅材，把阵法产能留给高阶批量生产，但导流槽等明确不上市的独门器物除外。目前规划的五元素**材料**只有空白灵石。v1.0配方均为单一目标产物的线性合成，不设计副产物；多条配方路线可以分叉、汇合，但一次配方执行不同时产出副产品。

材料品级先采用宽范围的标准灵气成本预算，而不是给每件材料规定相同成本：下品从单属性下品灵石1块起，至五种属性合计下品灵石100块为止；中品、上品、天品的讨论上限分别为同品级属性灵石合计300、600、1,000块。后三级的成本下界、各属性分配、基础材料数量和具体配方尚待逐项平衡；`100／300／600／1,000`是上限，不是每件材料的定价或必需投入。

### 炼器制造

炼器以灵气代替人工劳动，主要付出材料、灵气和较短制作时间。

床的当前设计基线为：

```text
材料：木头 ×16
炼器灵气：200
炼器时间：1分40秒
```

该数值用于原型中比较制造方式，最终材料、灵气与工量仍需平衡验证。

### 手工制造

玩家可以按图纸使用材料手工组装器物。手工制造不依赖炼器阵，但必须遵守以下规则：

- 当前时间惩罚倍率为炼器时间的25倍；
- 手工制造独占主角，期间不能同时执行其他需要主角亲自完成的行动；
- 手工制造允许离线推进，与在线时使用同一套进度规则；
- 开始制作时一次性扣除全部配方投入；主动中断会清除进度、损失全部已投入材料且不产出成品，不能分段退料；
- 关闭页面或进入后台不视为主动中断，进度仍按离线规则推进；
- 只要携带了图纸所需材料，玩家可以在资源点手工制作蒲团等应急器物；
- 行囊容量因此同时制约可运回资源和可携带的应急材料。

按25倍计算，当前基线中手工制作一张床需41分40秒。该时间代表主角劳动的机会成本，不应成为可与采集、旅行、打坐并行的免费后台队列。

人工主持炼器阵允许暂停并保留已锁定的投入和进度；具备持续供灵的自动炼器队列则可在主角离开后继续运行。这两种状态不能套用手工制造的中断损失规则。主角自身灵气上限不限制可主持的阵法规模，可以分段输入灵气、打坐后继续；若使用聚灵珠中的外部储备，输入时优先消耗珠内灵气。功法依任务取得，配方没有额外理解门槛，高级配方所需的高级材料仍受任务解锁约束。

## 基础材料与灵气转化

### 金属种类

游戏中的金属材料只有一种，统称为“金属”。不通过铜、铁、银或合金种类堆叠制造成长。

高阶器物的差异主要来自：

- 器物结构和图纸；
- 阵纹与工艺；
- 投入的属性灵气及组合；
- 供能、容量、效率与控制方式；
- 品级与具体功能。

矿石、金液和固态构件可以表示同一金属在不同处理阶段的形态，但不因此变成不同金属种类。

金液转运、铁桶凝固、泥土模具、水冷却、地火冷却和导流槽堵塞的共用规则见[《物资、储物与批处理》](MATERIALS_AND_STORAGE.md)。

### 纸质炼器阵基线

当前开局数值基线为：

- 主角初始持有100点灵气；
- 纸质炼器阵驱动一轮消耗50点灵气；
- 初始灵气因此最多连续驱动2轮；
- 转化不设最低投料量，1份基础资源也可以启动一轮；
- 初级炼器阵按当前10%效率结算，使用1,000份对应基础资源可以产生100点目标属性灵气；
- 灵气的最小单位为1，每轮产出独立向下取整，不保存或跨轮累积不足1点的隐藏余数；因此投入1至9份资源会得到0点灵气；
- 纯转化效率不得超过100%，驱动灵气、转化损耗和逸散必须真实记录。

开局首次投料100份泥土执行土生金时，纸质炼器阵消耗50点主角灵气，金阵眼得到10点金生灵气，未完成转化的90点土生灵气进入宅院的游离灵气状态。界面必须在玩家催动前显示预计产出，包括产出为0的情况；允许玩家确认低效操作，但不能把损失伪装成程序错误。

开局数值将在首个垂直切片中验证。若采集、搬运和转化总时长使安全路径失去可读性或趣味，应调整数值，而不用隐藏补贴绕过规则。

## 属性灵气与赋能

### 无灵石时的灵气用途

开局没有空白灵石可以保存容易逸散的属性灵气。玩家可以将刚产生的灵气立即用于：

- 赋能匹配的工具；
- 驱动后续转化或炼器工序；
- 支付其他明确的生产做功成本。

开局的首个关键反馈为：

```text
挖取泥土
  → 土生金，得到金气
  → 将金气赋予锯子
  → 砍伐工量显著提升
  → 快速获得木头
  → 制作水桶
  → 前往灵泉取水
```

### 工具赋能规则

- 赋能将属性灵气绑定到特定用途，不是可逆的通用储能。
- 已赋能灵气不得从工具抽取、转移或改作其他用途。
- 工具作业时按实际完成的工量消耗赋能，闲置时已绑定灵气仍会缓慢逸散。
- 赋能只提高工作吞吐、降低可解释的作业损耗，或改变明确工序，不得从同一资源存量中凭空创造物质。
- 属性与工具效果应优先根据作业对象及五行关系决定，不为每个工具与灵气组合编写一套互不相干的特例。
- 界面使用无歧义倍率表示效果；“砍树效率`+1000%`”最终是指`10倍`还是`11倍`尚待确定。

首次教学中，10点金生灵气全部赋予下品锯后显示`+1000%`。赋能强度随时间自然减少；每完成一次强化砍伐再减少50个百分点，并在该次取得10份木头。赋能耗尽后，普通砍伐每次只取得1份木头。百分比是工具的赋能强度，不是允许存在半点灵气的另一种灵气单位。

首个垂直切片只需实现和验证“金气赋能下品锯”。其他工具与五种灵气的组合不得为了预留未来而提前扩展为大量空壳效果。

## 炼器阵品级与外围阵法

### 转化与灌注的反向取舍

炼器阵的本职是炼器和五行转化，灌注空白灵石只是附带能力。品级越高，资源转化越高效，但直接灌注属性灵石时浪费越大：

| 炼器阵品级 | 转化损耗 | 灌注损耗 |
| --- | ---: | ---: |
| 初级 | 90% | 0% |
| 中级 | 75% | 20% |
| 高级 | 50% | 40% |
| 天级 | 20% | 60% |

高品炼器阵仍可凭借更大的处理批量、更高的空白灵石品级兼容和外围阵法完成高吞吐灌注；低品炼器阵也不会因升级而完全失去用途。界面必须分别展示转化损耗和灌注损耗，不能用一个含糊的“阵法效率”合并两者。

### 外围阵法组合

炼器阵外围可以布设四象阵、三才阵、两仪阵、归一阵，以及六芒阵、七星阵、八方阵、九转阵等辅助阵法。每种外围阵法最多布设一座，不要求整套阵法使用同一品级；例如允许中级八方阵与高级三才阵同时工作。

外围阵法品级统一采用以下效果档位：

| 品级 | 对目标量的降低比例 |
| --- | ---: |
| 初级 | 10% |
| 中级 | 25% |
| 高级 | 40% |
| 天级 | 60% |

不同外围阵法只降低配方中明确指定的一个成本或损耗通道。六芒阵降低属性灵气需求、七星阵降低属性灵石需求、八方阵降低材料需求等映射目前只是设计举例，尚未正式冻结；不得仅凭名称在实现中自行补全。

成本降低按以下顺序结算：

```text
调整后需求
= max(配方规定的不可降低下限,
      ceil(基础需求 × (1 - 降低比例)))
```

离散材料的最低需求至少为1，且不得突破成品实际构成所需的守恒下限。外围阵法可以减少工艺浪费、辅助耗材、驱动灵气或其他明确可降低部分，不能让40份金属凭空成为含有100份金属的成品。若多个外围阵法共同作用于同一损耗通道，按剩余损耗乘算，避免负损耗和超过100%的利用率：

```text
最终损耗
= 基础损耗 × ∏(1 - 各阵法降低比例)
```

## 灵石生产、替代与供能

### 下品属性灵石构成

下品空白灵石与属性灵石的当前结构讨论基线为：

```text
下品空白灵石
= 金、木、水、火、土灵气各100

下品属性灵石
= 下品空白灵石 ×1
+ 目标属性灵气 ×100
```

例如，下品木灵石包含金、水、火、土灵气各100，木灵气200。按初级炼器阵当前`1000 → 100`的转化基线，若完全以基础资源人工生产，共需要五种基础资源各1000，以及目标属性对应的额外1000，合计6000份基础资源。空白灵石无法归元，因此商店对空白灵石的低价批量供应不会让玩家直接取回其形成时使用的五行灵气。

强行在自动化之前手工生产灵石是允许的低效路径，不应设置与世界规则无关的硬性禁止。该路径即使作为挑战玩法，也必须被正确结算并能够存档、离线推进与恢复，但不应通过强力奖励将其变成标准最优路径。

### 空白载体与永久稳定

空白灵石不是M02的第六种基础资源，而是M07拥有、由五行灵气凝结而成的器物。它可以灌注、封灵、储存、运输、交易并用于后期灵脉采掘，但没有归元方式。界面不显示“无法归元”，只是不提供该操作。

属性灵石完成灌注和封灵后永久稳定，不随时间逸散、降品或产生维护成本。同属性、同品级灵石可以按数量堆叠，不记录每块灵石的剩余能量。

属性灵石作为供能物时，一旦提交给阵法、傀儡或其他接收端便不可取回。供能不产生可以重新放回库存的“半块灵石”，也不允许高品灵石只释放一部分去适配低品器物。工序中断时已经提交的灵石如何损失或继续结算，留待对应供能原型确定。

### 高低品级替代

不同品级的阵法、傀儡和炼器配方可以要求对应品级的同属性灵石。玩家缺少目标品级时，可以用低一品灵石按`16:1`替代：

```text
下品属性灵石 ×16 → 替代中品同属性灵石 ×1
中品属性灵石 ×16 → 替代上品同属性灵石 ×1
上品属性灵石 ×16 → 替代天品同属性灵石 ×1
```

跨多个品级时逐级连乘，因此1块天品灵石需求可以由4096块同属性下品灵石替代。替代只在配方、建设或供能的当前提交中满足需求，不会生成一块可以带走的高品灵石。高品灵石不能向下替代低品需求；低品器物无法承受高品灵石，也不存在取出部分能量延长续航的操作。

同一批需求允许混合使用目标品级和低品替代。例如需要3块中品火灵石时，可以提交2块中品火灵石与16块下品火灵石。多属性需求分别校验，数量不足时整笔操作失败，不进行部分扣除。

外围阵法先降低配方声明的目标品级数量并完成向上取整，再计算低品替代。例如3块中品灵石经40%降本后变为2块中品需求，随后才允许用32块下品灵石替代；不得先展开为48块下品再利用另一种取整结果。

空白灵石、品级压缩、阵法灌注上限和灵脉采掘阵的详细规则见[《物资、储物与批处理》](MATERIALS_AND_STORAGE.md)。

## 交易、价格与灵石面额

属性灵石是标准化、易运输的生产资料和宗门硬通货。所有实际成交的最低价格为一块任意属性下品灵石，不存在零灵石成交或灵石小数；即使一只普通木桶的标准价值远低于一块下品灵石，也可以出现“一块下品木灵石购买一只木桶”的交易。低价物品可以通过成套出售或批量委托改善面额问题，但首个可玩切片不建立另一种通用小额货币。

当前设计方向为：

- 金属、木头、水、火和泥土五种可直接取得的基础材料不能在商店买卖；
- 五种基础资源均不能交易；空白灵石作为M07器物可以交易，当前批量价格基线为任意下品属性灵石一块购买下品空白灵石1000块；
- 普通家具、工具和其他加工器物仍可出售或购买；
- 商店可以将花洒、工具与耗材组成整套生产资料，再以灵石结算；
- 批量委托可以在交付多件商品后统一支付一块或多块灵石；
- 高级成品和可重复生产的图纸可以直接以灵石计价；
- 商店不应无限量以固定价格收购家具或其他人工产品；
- 紧急需求、特定人物、批量采购和限时委托可以产生高于平时的价格。

### 标准灵气成本与价格边界

物品的隐藏估值沿**默认配方的完整材料链**向前追溯，累计制造所需各级材料对应的五种属性灵气，再统一折算为下品属性灵石数量。金属、木头、水、火和泥土的投入数量不计入该估值；玩家亲自供应的灵气不从标准成本中扣除。估值使用未经外围阵法、生产者技术和实际损耗修正的默认配方链，而不是玩家实际选用的廉价路线；否则技术降本会反过来压低同一成品的标准价值。

配方链直接消耗的属性灵石也计入标准成本。底层统一以同属性相邻品级`16:1`折算为下品灵石当量：1块中品、上品、天品分别记为16、256、4,096块同属性下品灵石。这个比例只用于成本核算与投入替代，不是市场兑换价；给NPC显示报价或派发交易款额时，才按相邻品级`12:1`的市场向上兑换比例换算面额。各属性先分别记账，具体报价组合与离散取整仍由后续经济原型统一确定，不允许界面自行选择有利的舍入方式。

例如某物品的标准配方消耗五种属性灵气各50,000点，并另耗用100万份基础资源；基础资源不进入估值，按下品属性灵石每块对应100点目标属性灵气的当前基线，其10倍最高成交估值为五种下品属性灵石各5,000块。

NPC对一件物品的最高成交估值为标准灵气成本的10倍。玩家挂牌不受这一上限限制，可以标出任意离谱但不低于最低面额的价格；超过NPC支付意愿的挂牌不会被系统强行禁止，只是不会有NPC成交。

NPC商人出售物品时，隐藏的最低可接受价格为标准灵气成本的2.5倍。初始报价可以受库存、关系、人物性格和供需影响，玩家能够砍价，但低于隐藏底价时NPC拒绝。界面不公开公式和准确底价，可以通过对话反馈让玩家判断对方是否仍有让价空间。

NPC发布的炼器采购任务，报酬范围为标准灵气成本的0.1倍至4倍；最终离散支付仍不得低于一块任意属性下品灵石。低倍率委托可以体现宗门对新人的压价，却不保证后续回报：某些任务会在很久之后才触发同一NPC的新任务，甚至当下看起来只是一次性委托，接取前不会许诺或透露隐藏后续。替代配方与外购材料可能让低倍率任务也有利润。设计目标是让玩家逐渐形成模糊的成本判断，而不是要求每次交易都精算完整材料链。

### 任务接取、整批交割与保证金

- 只有主线任务强制获取且没有完成时限；其他任务由玩家自愿接取，均有完成时限，接取时可以要求保证金。
- 首阶段只开发NPC发布的额定交付任务：交付数量、截止时间和报酬固定；不开放议价、延长交期、提高报酬、低品抵高品、提前交付、分期交付或转包其他宗门弟子。游戏没有残次品或良率概念。
- 玩家接取时指定交割地点及该地点的仓储设施，并可设置到交割期自动提交。交割时只检查所指定仓储设施中的合格物品；不从主角行囊、其他仓库、设施输入槽或运输途中的货物自动拼凑。
- 交割按整批原子结算：供货方库存和采购方货款都足够，才一次性交换全部合格物品与货款；少一件也不能部分扣货或部分给钱。交割前货物不预留，玩家可以卖掉或挪用，但必须承担到期库存不足的后果。市场购得的合格物品也可以用于交割，来源不受限制。
- 周期性任务可以设置自动接取、自动化批量生产和到期交割。供货方的保证金接取时锁定在任务上，跨成功周期沿用，确定不接下一期时返还；交货失败则归采购方。供货方失败次数写入隐藏履约系数，提高后续所有需保证金任务的金额，后续成功会逐步降低该系数；实际应付金额须在接取前显示。

### 主角发布采购与双向履约

三元素材料解锁后，主线也应让主角习得中级炼器术，并将灵气上限提升至1,000。此时主角可以作为采购方发布材料求购或代工任务，设定报价、供货方保证金比例和交货时限，与愿意接单的NPC议价；NPC也可以要求主角提高报酬。它仍沿用整批、到期、指定地点与仓储设施的交割规则：NPC交来的货自动进入玩家指定仓储，可以据此设置周期性补货。主角的采购任务仍须实际备足灵石，发布时不预扣或锁定全部货款。无属性灵气成本的独门器物如导流槽不进入这一市场采购体系。

交割期区分两类违约，不能都写成“任务失败、没收保证金”：

| 到期状态 | 货物与货款 | 供货方保证金 | 后果 |
| --- | --- | --- | --- |
| 双方履约 | 整批交货并付款 | 退回供货方；自动续期可继续锁定 | 任务成功 |
| 供货方缺货或未交齐 | 不交货、不付款 | 转交采购方 | 供货方履约记录恶化，之后需付更高保证金 |
| 采购方无法付款 | 不交货、不付款；货物仍属供货方 | 退回供货方 | 任务立即终止，采购方信用受损 |

采购方既可能是玩家，也可能是NPC。采购方到期无款时不形成欠债、补款或延期交付记录；若违约者是主角，后续发布任务的基础费用提高，但仍可通过更好的条件让NPC接单。NPC是否会付款也可以由任务内容与人物性格明确设定，例如压价委托的采购NPC可能必然在交割时无款，而不是假定所有NPC拥有可模拟的完整钱包。保证金始终绑定任务锁定，NPC不能另行侵占；采购方违约时不得没收供货方保证金。不同人物可以用剧情模板回应违约。

NPC记得自己发布的任务被接取、拒绝、完成或失败；拒绝不算供货失败。具体人物性格可以决定是否再次发布同一任务、每次小幅加价以及后续叙事，不要求提前向玩家解释隐性收益。

保证金失去后的下一期能否自动续接、交割前能否改换指定仓库、周期频率、双方同时缺货与缺款时的违约归属、履约系数和采购方信用费率公式尚未确定，不由实现自行补全。任务生命周期由M09负责，库存扣除由M06的真实仓储边界处理，灵石支付按M07、M08的契约结算。

### 兑换、替代与套利

属性灵石的市场兑换继续采用同属性向上`12:1`、向下`1:8`的不对称比例。它与配方及供能中的`16:1`低品替代不同：市场兑换产生可以储存和交易的高品或低品灵石，替代只满足当前提交。

在正式配方表形成后，应使用统一脚本从标准灵气成本批量计算基准价格，并检查购买、分解、制造、交易和品级兑换形成的经济路径。技术、地点、库存、委托、时间和关系造成的有界套利是正式玩法；同一地点以固定价格和无限库存反复执行、没有决策和机会成本的封闭获利循环属于缺陷。

## 首个可玩闭环

### 首次开场与界面展开

首次游戏按以下顺序建立世界、界面和操作语法：

1. 游戏加载后依次显示“金、水、木、火、土”，组成以圆盘为背景的五角星，随后出现“炼器宗 / Refining Sect”标题。
2. 标题上移并缩小到置顶窄Banner；五行圆盘缩小到粗糙卷轴上的纸质炼器阵，卷轴外出现剧情对话框，交代主角在外门大比取得前十、依规进入内门。
3. 纸质炼器阵图标移向左侧并展开背包栏，剧情框移向右侧并展开功能栏；中央显示一进四合院式的筑器峰114514号宅院，并说明将阵图拓印到中央空地后即可成为见习炼器师。
4. 背包栏显示免费工具、下品行囊和“设施”栏中的宅院家具，但不提供基础资源；右侧显示“剧情”“地点”“动作”“任务”栏位。
5. 背包下方显示主角灵气`100`。剧情要求玩家把纸质炼器阵放到桌上展开。
6. 教程用箭头明确指示：点击纸质炼器阵，点击“设施”，再点击桌子。
7. 中央展开纸质炼器阵，阵眼可点击查看信息；“地点”栏首次只显示泥沼。

### 初次采土与土生金

8. 玩家前往泥沼时不产生旅行时间，场景切换到山间泥潭。
9. 玩家点击木桶将其拿在手中，再点击泥潭开始装土。下品木桶容量为10，装满后停止；玩家点击行囊，将桶中泥土倒入行囊。该过程重复至行囊携带100份泥土。
10. 剧情提示返回宅院，使用主角自身灵气催动纸质炼器阵。
11. 回到宅院后纸质炼器阵展开。玩家打开行囊，点击泥土后一次取出全部100份，放到土阵眼，再从“动作”栏选择“催动炼器阵”。阵图显示运转动画，主角灵气持续消耗，累计消耗50点后停止；金阵眼出现10点金生灵气。
12. 剧情指出纸阵只有约一成效率，画面顶部显示本区域“土生灵气 90”，明确表现转化损耗已经泄漏到环境。
13. 主角决定向内门藏经阁长老询问提高效率和处理泄漏的方法，自动获得主线任务“去内门藏经阁求教”。
14. 模拟时间暂停。剧情说明刚产生的灵气若不及时使用，会在5息后开始消散；教程指示玩家全量拿起金阵眼的金生灵气并放到锯子上完成赋能。暂停期间所有模拟倒计时一并停止。

### 赋能砍树、储料与取水

15. 锯子显示`+1000%`并开始随时间衰减。模拟时间恢复，剧情要求玩家赶往新显示的丛林；场景切换到椰树林。
16. 游戏不再逐步指示砍树操作。赋能锯每次取得10份木头并额外降低50个百分点；金气使用过程产生的最小单位逸散会使区域顶部金生灵气在1与0之间出现变化。赋能归零后，继续砍树每次只能取得1份木头。
17. 返回宅院后，教程引导玩家把行囊中的木头存入柴房。剧情揭示拓印初级固定炼器阵需要泥土、木头和水各2,000份。
18. “任务”栏显示第二个主线任务“积攒足够数量的基础资源”，并分别显示三种材料的`当前数量 / 2,000`。
19. 剧情提示木桶同样能够装水，“地点”栏显示灵泉；玩家点击后切换到泉眼场景。
20. 游戏不再限制取水次数，首次操作教学在此结束。此后由任务、事件和进度逐步揭示地点与机制，不再持续使用强制箭头规定操作顺序。

### 教学后的首个工程目标

初级固定炼器阵的拓印配方为：

```text
泥土 ×2,000
木头 ×2,000
水   ×2,000
```

首次游戏从空仓开始取得全部材料；重置或通关后重新开始时，三种材料各有1,000份开局库存，但仍需补足另外一半。高炉和炎坑不属于拓印奖励，仍由玩家在后续流程自行兴建。

首个垂直切片应以以下玩家流程为主线：

```text
获得宅院、纸质炼器阵和内门初始工具
  → 在首次操作教学中把纸质炼器阵铺到桌面
  → 前往泥沼，以初始木桶和行囊取得100份泥土
  → 使用纸质炼器阵执行土生金
  → 看见10点金气与90点泄漏土气
  → 将刚产生的金气赋能下品锯
  → 以明显更高的吞吐砍伐树木
  → 将木头存入宅院柴房
  → 携带木桶前往灵泉按容器容量取水
  → 使用木头按图纸制造额外木桶
  → 保存进度并在刷新后继续
```

首个切片只需实现完成上述闭环所需的最小规则。灵石生产、高级工具、傀儡、商店完整结算和自动化网络只作为当前规则的后续方向，不纳入首个切片实现范围。

## 首个切片的验收不变量

- 玩家无需开发者口头指引即可找到至少一条通往灵泉取水的可行路径。
- 首次游戏、重置游戏和通关后重新开始能够稳定选择各自的初始库存、地点显示和教学提示状态；跳过教学不会阻断后续任务与剧情。
- 纸质炼器阵允许任意正整数投料，并按每轮独立取整；重复投入不足产出1点灵气的小批次不能通过隐藏余数获得额外产出。
- 泥土与水的采集、携带和运输受木桶等容器的数量与容量约束，不退化为无容器的单点点击收集。
- 主角每次点击手工采集只立即结算一次；木桶容量和工具、灵气赋能效果真实生效，不因动画帧率额外产出。
- 将蒲团、家具或关键工具归元后，功能和恢复路径与文档规则一致。
- 手工制造开始即扣除全部投入，主动中断全部损失；期间主角不能另外执行亲力行动，关闭页面后仍按相同速度推进。
- 金气赋能锯子只改变可解释的砍伐工量或损耗，不凭空增加资源点总物质。
- 游离灵气、工具赋能和资源变化可以由真实模拟快照解释，不由动画帧率或界面特例决定。
- 在纸质炼器阵的低效转化和驱动成本下，手工冲击灵石不是无成本或明显最优的开局策略。
- 保存、刷新和离线返回不会丢失功能物品、制造进度、赋能余量、游离灵气或已产生的资源变化。

## 待验证与待定事项

以下问题尚未因本文档定稿：

- 主角的灵气上限、一次完整打坐的结算方式，以及200点炼器成本如何跨越当前灵气持有量；
- 床与蒲团能否中断、睡眠完成前是否产生部分恢复，以及恢复行动的离线结算交互；
- 工具赋能的容量、绑定效率、每单位工量消耗和闲置逸散速度；
- 金气赋能下品锯的最终倍率及无歧义界面文案；
- 功能物品在库存、宅院安置、携带和装备状态之间的具体切换成本；
- 床、蒲团、花洒、铁镐、冲击钻和各类傀儡的最终配方与工量；
- 灵石提交供能后遇到工序中断、设施损坏或输入锁失效时的最终结算；
- 标准成本换算为NPC可见报价时的多属性面额组合与离散取整；
- 普通商品的批量委托规模、商店找补方式与是否需要本店余额；
- 当前早期物品造价讨论稿的最终材料、图纸价格、炼器耗能、制作耗时与手作工量；
- 下品聚灵珠的容量、重复使用规则、灌注与取用方式、损耗和溢出处理。

上述项目应通过首个垂直切片、后续对应玩法原型或单独设计决定逐项确认，不得在实施中默认补全。
