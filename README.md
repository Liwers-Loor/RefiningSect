# Refining Sect｜炼器宗

> 以中国五行为基础，围绕资源开发、阵法轮转、生产自动化与灵石贸易展开的网页放置增量游戏。

## 项目简介

在《炼器宗》中，玩家将扮演炼器宗的一名内门弟子。主角获得了一处属于自己的宅院，以及一张简陋的纸质炼器阵图。宅院附近分布着灵泉、地火、丛林、矿脉与泥沼五处资源点，但最初的主角既没有成熟的生产设施，也没有取之不尽的灵气。

玩家需要亲自采集和搬运材料，利用五行之间的相生相克关系取得新的资源，逐步将纸上阵图拓印到宅院地面，并建设一座能够自行采集、加工、输送和调度资源的五行炼器大阵。

游戏的成长不只表现为数字变大，也表现为劳动方式的改变：

```text
肩扛手提
  → 资源点自动采集
  → 材料就地加工
  → 五行线路自动输送
  → 整座炼器阵自行调度与生产
```

## 核心玩法

### 五行轮转

五行炼器阵以金、木、水、火、土五种灵气维持运转。

- 相生用于生成、延续和推动生产。
- 相克用于开采、切割、熔炼、淬火与材料加工。
- 五种灵气能够在阵眼和资源点之间流动，形成可以观察和调整的生产线路。
- 阵法动画将忠实呈现资源的真实流向、缺料、堵塞与过载，而非作为与数值无关的装饰。

### 质料与守恒

这个世界遵循质能守恒。任何纯粹的五行转化都不会超过100%的效率；初级炼器阵会产生严重损耗，玩家需要通过阵法、设施和技术进步逐渐减少浪费。

实体质料可以归元为灵气，灵气也可以作为做功能力，用于从真实资源点获取材料。例如：

```text
泥土
  → 土生金，炼出金生灵气
  → 金克木，以金气砍伐树木
  → 获得木头
  → 制作水桶
  → 前往灵泉取水
```

灵气灵活却容易逸散，实体材料笨重却便于长期保存。玩家需要在即时生产、物资储备和运输成本之间作出选择。

### 生产自动化

五处资源点既是原料产地，也是生产网络中的加工节点。

玩家可以在资源点建设聚灵阵、熔炼设施、储料设施和五行线路。例如，将地火勾联至矿脉，可以通过“火克金”就地熔炼矿石，再利用耐火导流槽将金液送回宅院。

自动化不会凭空创造资源。每一条线路都具有真实的输入、输出、容量和机会成本；资源点的天然灵脉流量也需要在材料生产、灵石灌注与线路维持之间分配。

### 灵石与商业

当五行灵气齐备后，炼器阵可以在中央凝结空白灵石。空白灵石是可交易的生产资料，但只有完成属性灌注与封灵的灵石，才是宗门通行的硬通货。

属性灵石既可以用于交易，也可以放入对应阵眼供能。供能过程存在两层损耗：

- 灵石品级决定灵气的释放效率。
- 炼器阵等级决定阵眼的吸收效率。

灵石分为下品、中品、上品和天品。相邻品级采用不对称兑换：

```text
1块中品属性灵石 → 8块同属性下品灵石
12块同属性下品灵石 → 1块中品属性灵石
```

这种价差体现了高位炼器师对高品灵石生产与兑换渠道的垄断。玩家可以依靠炼器生产发展，也可以通过天然灌注、代工委托、品级兑换和五行市场价差完成原始积累。

## 表现形式

《炼器宗》计划采用二维网页界面：

- 使用像素画 Banner 与文字呈现宅院、资源点、人物和宗门事件。
- 使用可交互的阵法图表现五行炼器阵与生产线路。
- 通过阵纹轮转、灵气流动、阵眼明灭和器物成形，表现自动化机器般的运行过程。
- 不追求高成本的3D场景，将开发重点放在系统深度、反馈清晰度与长期成长体验上。

## 设计方向

本项目希望支持多种可以相互混合的玩法：

- 建设高吞吐量五行生产线的自动化玩法。
- 研究材料、配方和阵法组合的炼器玩法。
- 开发资源点并利用天然灵脉的经营玩法。
- 承接师弟师妹灌注委托的代工玩法。
- 利用品级、属性、时间与地域价差的商业玩法。

玩家不需要在开局永久选择职业。生产方式、资源分配与商业策略本身，将逐渐塑造每一处宅院不同的发展道路。

## 技术方向

当前计划采用以下技术路线：

- Svelte 5
- TypeScript
- Vite
- SVG 与 CSS 动画
- `decimal.js`
- Vitest
- Playwright

游戏模拟、界面渲染与动画表现将彼此分离。动画帧率不会决定资源产量，存档也将从第一版开始采用明确的版本与迁移机制。

## 当前状态

项目目前处于概念设计与仓库治理阶段，尚无可玩版本。

当前工作重点包括：

- 明确世界规则、资源体系与经济系统。
- 建立开发纪律、文档权威与本地验证门禁。
- 定义第一段可玩流程及其验收标准。
- 在规则稳定后搭建技术基础与首个垂直切片。

## 灵感来源

游戏的阵法轮转与“机器逐渐运作起来”的表现思路，受到经典网页放置游戏 [The First Alkahistorian](https://elemental-inception-incremental.g8hh.com/Elements/Elements.html) 的启发。

《炼器宗》将以中国五行的相生相克、炼器生产、宗门生活和灵石经济为基础，发展自己的世界规则与玩法结构。
